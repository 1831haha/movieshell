# v0.233.0（2026-10-26）

阅读章节切换逻辑全修：上一章按钮回尾页，翻页模式手指也能滑过章界。

## 问题

- 第三章回第二章，底栏“上一章”按钮直接落到第二章开头，
  应该回第二章尾页——用户刚从尾页过来，回去却要从头翻。
- 翻页模式（默认左右覆盖）手指滑到章末/章首就弹回原地、
  进不了上下章，只能靠按钮/音量键；滚动模式 195 已有越界
  跨章，翻页模式一直漏着。

## 全链路审计（修前）

- 回上一章三条路：音量键上一页、滚动越界、底栏上一章按钮。
  前两条早就对了，都是用 1_000_000_000 哨兵落到上一章尾页
  （分页引擎对超大偏移钳制到末页，滚动模式 scrollTo 自带
  钳制）；唯独底栏按钮漏了哨兵，一直落章首。
- 翻页模式手指越界：HorizontalPager 没有任何越界处理，
  章内滑动全被 pager 吃掉，边界余量没人接。

## 修复

- 底栏“上一章”按钮补上同一个哨兵，与音量键、滚动越界
  两路对齐，回去落尾页。
- 翻页模式加 pagerBoundaryScroll：复用滚动模式同款
  NestedScroll 机制，pager 在边界吃不下的横向余量走到
  onPostScroll 的 available.x（左滑为负→下一章、右滑为正
  →上一章尾页），一手势只跳一次；章内滑动全被 pager 吃掉、
  余量为零，不会误触。
- 目录、进度条、书签是明确选章（或带保存偏移），走章首
  或保存位置是对的，没动；前进方向落新章首页、首页顶部
  印章名，也没问题，没动。

## 技术点

- ReaderScreen 底栏上一章：jumpTo(chapterIndex - 1) 改为
  jumpTo(chapterIndex - 1, 1_000_000_000)，与 pageUp、
  boundaryScroll 两路同款哨兵。
- 新增 pagerBoundaryJumped / pagerBoundaryScroll，接在
  HorizontalPager 的 modifier 上；不新增 import（nestedScroll、
  NestedScrollConnection、Offset 本文件已有）。
