# v0.240.0（2026-10-26）

三处纠偏：详情弹窗真正改小、越界回上一章落末页修好、
阅读进度条改回本章进度。239 那版进度条方向理解错了，本版改回。

## 做了什么

- 详情弹窗真正改小：239 那版只收了封面和间距，整体还是
  接近满屏，看着像没改；本版宽度收进屏幕 80%，封面再缩
  到 72x96，行距、分隔间距、动作小钮同步收紧；作者、来源、
  最新、分组、追更、目录、收藏、净化规则与底部删除/阅读两钮全在。
- 越界回上一章落末页：手指越界回上一章时，恢复位置那一步
  有竞态——正文一到就先滚了顶，末页恢复常被后到的一次长度
  变化洗成章首，看着就是“直接到了上一章开头”。现改按章认领：
  同一章只恢复一次；正文没到时等着不滚顶；滑到底前等一帧
  让新正文完成布局。向前越界进下一章章首、上一章/下一章
  按钮、音量键翻页的落点都不变。
- 阅读进度条改回本章进度：239 改成全本位置是理解错了用户
  原话；本版改回——滑杆即本章进度（滚动模式取滚动比例，
  翻页模式取当前页比例），拖动松手只在本章内定位，不跨章；
  换章仍走上一章/下一章按钮；顶栏百分比不动。
- 阅读底栏精细化：原来两排裸文字按钮加一根深色粗滑杆，
  糊在正文底下没分隔，看着生硬；现加顶部细分隔线，滑杆
  改柔和轨道色（未走部分淡灰、已走部分主题色、圆点同色），
  上一章/下一章加小箭头，设置补图标，底栏自成一块。

## 核对（没动功能）

- 弹窗宽度只改了书籍详情这一处，TechDialog 默认仍走平台
  默认宽，其他弹窗一个不动。
- 恢复逻辑只改了“何时滚、滚哪”的认领规则，进度保存、
  书签、目录跳转、换源对齐的落点语义都不变。
- 双自查全绿。
