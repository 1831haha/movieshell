## 改法

- 所有弹窗页跟随系统主题：TechDialog 深色主题仍走深底、浅色主题走浅底（标题深底金字、浅底深金棕，渐变描边保留）；内容色一律跟主题 onSurface/onSurfaceVariant。193 写死的浅色是针对恒深色的临时解，本版一并改回主题色，涉及：书架操作表/详情/分组弹窗、阅读器目录与设置胶囊、音乐队列弹窗、切换音源选项行、Cookie 卡片、书源名、探源弹窗。海报全屏查看那个黑底 Dialog 是看图用的，不在此列。
- 书架写入串行化：NovelStore 加一把索引写锁，add/remove/updateSource 三处写索引共用；快速连点多本书不再互相覆盖。读侧不加锁。
- 导航章过滤：标题 exactly 是“首页 / 电脑版 / 书架 / 上一页 / 下一页 / 上一章 / 下一章 / 返回首页 / 返回 / 手机版 / 电脑端 / 触屏版 / 目录”的章直接丢掉。两处设防：拉目录时（PY 与 JSON 规则）过滤，已入库的老书读盘时也过滤，不用重加就干净；过滤后按位置重排 index，与阅读器的位置口径一致。
- 音量键跨章：章末按下一页键进下一章、章首按上一页键回上一章末页（滚动与翻页模式都接）。注意：跨章用的是音量键；手指滑动到最后一页仍停住（ pager 滑不出边界），要跨章点底栏“下一章”或用音量键。
