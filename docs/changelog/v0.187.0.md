## H03：PY 桥超时与 PHP 空上下文（本版新增）

- `ChaquopyEngine.kt:33` PY_TIMEOUT_MS = 15_000L，与 V8 的 JS_TIMEOUT_MS 同档；`146` 新增统一入口 `callBridge`，invoke 与 bookInvoke 均改走它；`157` 以 `withTimeoutOrNull` 等待，超时返回失败 JSON 并用 Log 与 LogBus 双通道记规则路径与调用名。
- 关键取舍：Chaquopy 桥是同步阻塞接口、不响应协程取消，直接套超时要等阻塞返回才生效；本版把桥调用放进与调用方脱钩的独立 `pyCallScope`，调用方只带超时等结果，15 秒必放行。
- 限制（请如实保留）：超时不等于中断 Python，后台 Python 仍会跑到结束、结果被丢弃；PySourceManager 取消旧 Deferred 只取消协程等待，停不掉桥上正在执行的 Python，这是 Chaquopy 桥的固有限制，本版没有、也无法假装修掉。附带修正：`callBridge` 先透传 CancellationException 再捕获普通异常，原先把取消也吞成失败 JSON 的口子已堵住。
- `PhpCliEngine.kt:136-137` runQuery 在 appContext 为空时显式设 lastError 为“应用上下文未就绪”并记日志，不再静默返回 null。

## H04：DrpyEngine 错误通道与静默空结果（本版新增，收窄版）

- 按审计建议“不改接口签名也可先做”的那条做，不重构全部引擎接口；UI 空态展示未改，见限制。
- `DrpyEngine.kt:26` 接口新增 `val lastError: String?`，带默认实现 null，其他实现类无需改动即可编译。
- `V8DrpyEngine.kt:61` 以 @Volatile 实现 lastError：引导失败、未载入规则、eval 超时/关闭/普通异常、返回空串或 null 或 undefined、解析 error 字段与解析异常均写原因并记 LogBus；eval 成功与换规则、释放时清零；原只记 android.util.Log 的解析日志已全部改走 LogBus。
- `DrpySourceManager.kt` 7 个入口全部加失败记录，适配器透传 lastError；`SiteRepository.kt:103-116` 按站记最近失败原因（内存 map，不落盘），logged 吞异常时记站名与原因，空结果时桥接对应引擎 lastError。调用方口径：空结果且 lastError 为 null = 源没数据；空结果但有原因 = 执行失败。
- `Type4Api.kt` 新增 lastError、网络与解析异常写原因并记 LogBus；play 双试探拿到有效响应时清掉首试探残留原因。
- 限制：订阅 drpy/PY 站的池适配器与 PY 适配器沿用接口默认 null，订阅站失败仍表现为没数据；CMS 与蜘蛛站无 lastError 载体，只有 logged 异常原因，无异常的空列表仍无法区分；聚合搜索普通异常静默（属 M28 范围外，未动）；PhpCliEngine 退出码非 0 但输出恰好有合法 JSON 时 lastError 仍非空的语义矛盾仍在（审计 M14 遗留），但 SiteRepository 只在结果为空时读它，不污染空态判断。

## H15：StoragePaths 权限切换与迁移丢文件（本版新增）

- `StoragePaths.kt:54` 迁移标记换 v2 键，v1 下未搬完也被误标已迁移的情况会重跑一次；已删干净的旧目录重跑是空操作。
- `migrateFromPrivate` 重写（`375` 行起）：目标不存在则复制；目标已存在先比长度再比 SHA-256，内容一致不动，内容不同留较新者（源较新覆盖、目标较新保留）；类型冲突记失败；只有整目录全部项确认已迁移才删源目录，任一项失败整目录保留并返回 false、不置迁移标记，下次启动重跑。旧“目标已存在则跳过、最后只看存在就删源”的口子已堵住。
- 相对路径：`toRelativePath`（`218`）、`resolveStoredPath`（`258`）以逻辑根 xiaying 为基准；新增记录存相对路径，读取时拼当前根；存量绝对路径兼容读取——以当前公开根、旧公开根、旧私有根或旧私有散落目录开头时剥离再拼当前根，不在已知根下的绝对路径与网络地址原样返回。DownloadStore 读回与落盘全量互转；SubSiteStore 仅对 drpy 与 py 记录的 api 互转，CMS、type4、spider、unsupported 的 api 是接口地址或标识，原样不动。MANAGE 权限未收回，存量规则与下载不断。
- 权限切换提示：迁移成功且确实搬了文件时在迁移函数内 Toast 一次，写清旧位置与新位置的运行时真实路径；迁移失败时 MainActivity 原有 Toast 保留并扩写；无文件可搬时静默。
- 限制：迁移只做私有到公开单向，撤销 MANAGE 权限后没有反向搬回，文件留在公开侧、相对记录解析到私有根暂时找不到（但 DONE 不会因此误降级），恢复权限后即恢复；v1 时代已按旧规则删掉源目录、较新私有文件已被跳过的情况，数据已丢，v2 重跑无法恢复；不在已知根下的绝对路径落盘时保持原样，只是不享受换根跟随；`repairOnUpgrade` 仍可能把仅存在于另一根的文件判丢失并按订阅重下（无数据丢失，可能多一次下载）。
