# v0.172.0

本版只有一件事：直播订阅管理里加“一键导入稳定直播源”。

## 一键导入稳定直播源（直播订阅管理页）

- 位置：直播订阅管理页顶部，“添加订阅”那行上方，新增一个全宽按钮，
  文案“一键导入稳定直播源（11 条）”。
- 点一次即导入下面 11 条，导入后弹提示“新增 X 条，已有 Y 条”，
  然后自动刷新频道列表：
  白嫖军团、拾光直播源、自动更新直播、推荐直播、长苏影视、
  蓝天白云、六维直播、热舞直播、B站直播源、YueChan Global、
  Joevess央卫3（地址与任务书逐字一致，不多加、不换地址）。
- 重复点只补缺失：已在列表里的按 url 去重不重复加，提示里的
  “已有 Y 条”就是这次没新增的数量。

## 不内置、可删除（本版红线）

- 绝不在 App 启动、LiveStore.init、refresh 里自动添加这 11 条；
  只在用户点按钮时导入一次。
- 导入后每条就是普通 LiveSource，和手工加的订阅完全一样：
  在订阅管理里点每条的删除图标就能删；删了以后 App 不自动补回，
  没有任何“缺失即补全”逻辑。
- 没有把这 11 条写成写死的频道列表，也没有改 LiveStore 的频道聚合逻辑。

以下几条按订阅拉取会解析出 0 频道或一堆分片假频道，
所以本次一律不导入，也没有擅自把它们改成手动频道：
- rtmp 单条流：TVBS新闻、非凡新闻（rtmp 单频道地址不是播放列表）。
- 单个 m3u8 纪录片/风景台：人与自然、自然传奇、探索发现、地理中国、
  航拍中国第一季、航拍中国第二季、直播中国主频道、八里沟桃花湾瀑布、
  黄山（切分处名称不全那条）、丽江古城大水车、乌镇西市河、泰山主峰
  （单个 m3u8 是单台流，不是含多台的播放列表）。
- php 单源：凤凰中文、菜妮丝直播（IPV6.php）（php 直出单路或需参数，
  按 M3U/TXT 订阅解析不出频道列表）。

## 已知限制

- 这 11 条用的是截图绿标，没有重新逐条测活；某条源站下线或改地址时，
  导入后刷新会在直播页提示“以下订阅未解析出频道”。
- 导入后刷新走 LiveStore.refresh 的 15 秒单源超时，与手工订阅一致。
- 本版未动 171 遗留的其他审计项（引擎超时与并发、嗅探请求头、
  换内核、字幕跨集、订阅刷新重试、MD5 信任锚、删源残留、
  详情进程重建、应用内更新日志、设置页“关于侠影”占位、死代码清理）。
