# v0.213.0（音乐三路自查两批：界面误导 + 播错丢状态）

## 界面误导批

- 搜索失败不再谎报“没搜到”：失败不清空旧结果，无结果时给 Error 档“搜索失败”+重试，有旧结果时顶行明说“上次搜索失败，显示的是上次的结果”；搜索结果顶行补“共 N 首”。
- 榜单失败不再谎报“暂无榜单接口”：失败显示“榜单加载失败”+点击重试（咪咕真无接口的文案保留）。
- 迷你条加载时三个控制钮不再整个消失，上一首/下一首始终在，转圈只嵌在主按钮里，与播放页同款。
- 删音乐源、删本地歌改走确认弹窗；本地歌弹窗明说联动删收藏/歌单/历史。
- 播放页音质项只展示不点击，现在整体置灰，一眼可辨。
- Cookie 输入框默认遮掩，点“显示/隐藏”切换明文。
- 测试弹窗标题按被测源区分内置/自定义，副标题显示源名。
- 本地/收藏/歌单三页加载中只转圈，不闪空态；歌单空态文案“点 ⁺ 加进来”改实。
- 音源管理无源时补空态说明；队列弹窗打开直接滚到当前歌曲。

## 播错丢状态批

- 解析失败回滚下标：失败时 index/queueState 滚回旧值（换过队列时旧下标越界则归 -1），队列弹窗不再高亮没在播的歌，下一首/播完自动切歌不再从错位置算。
- 一次性指定源不再泄漏：forced 改在起播入口捕获即清零、随本次解析传入；本地歌不走解析、解析被取消时都不留给下一首。
- 指定源失败回落其他启用源（原来只剩 GD），全部失败才走 GD，与注释的回落顺序对上。
- 解析逐源重校验启用态：每源尝试前重读注册表，已删/已禁直接跳过。
- 跨平台切歌世代守卫：切歌后旧搜索返回直接丢弃，不再把播放拉回旧歌。
- 首选源持久化：改 StateFlow + SharedPreferences，进音乐页恢复一次，芯片跟 Flow 走；源管理禁用/删除首选源时立即清掉，重新启用不再静默复活。
- 切回自动立即重解析（与选具体源对称），本地歌不重播、进度不丢；列表页与播放页选源时本地歌都不重播。
- 删歌同步播放器：本地歌删除确认成功后，删当前歌停播清显示态，删队列里的歌剔出队列并修正下标。
- 队列与下标持久化：进程重建后恢复队列快照（不自动起播，点队列项再播），stop 时清掉。
- 渐弱防重入：新渐弱/新起播先取消旧渐弱，尾巴不再暂停刚恢复的新歌。

## 本轮没动的（留下一批或待用户定）

播放页切源只管一首、列表页切源管以后的语义是否统一；进程重建后搜索框与结果恢复；歌单侧删歌是否联动播放器；队列行内删除/清空；音乐列表时长（模型无 duration 字段）；服务被杀后控制器 stale（疑似，需真机验证）；播放失败是否自动跳歌。详见《音乐三路自查报告》。
