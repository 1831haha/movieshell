# v0.241.0（2026-10-26）

回上一章落末页这一次真修到根上，外加阅读设置改成底部小面板。

## 为什么 240 没修住

240 只修了恢复效果本身，但翻页模式（左右覆盖）下还有两路
会把刚落好的末页洗回章首，240 一处都没碰到：

- 重分页效果：每章正文的中英文混排比例不同，每页字数
  （charsPerPage）换章就变，变化一来就触发重分页定位；
  它用的偏移是旧章页码对应的陈旧值——用户从旧章第 0 页
  回来时那个偏移就是 0，恢复效果刚落好的末页就被它盖回
  第 0 页。按钮、音量键、手势三路换章全走这条死路。
- 手指越界手势：右滑回上一章时手势还没结束，pager 的回弹
  settling 也会把页码拽回 0，恢复效果落点落早了等于白落。

GPT 那份简报说的“翻页定位逻辑错了，从下往上滑回来应该停
在上一章章尾”就是这回事；简报里的修法 1（记住方向、回
上一章定位到章末）已按上面两路落地。修法 2（连续滚动、
整本无缝接）是另一个大改动，本版先不做；修法 3（缓存）
本来就有——换章时前后各一章早已预加载，回看不重新请求。

## 做了什么

- 回上一章落末页（根治）：换章时立落点认领，恢复效果只在
  手势结束且分页就绪时落点，落到目标页才清认领；重分页
  效果在换章当次直接跳过，落点只归恢复效果管；分页未就绪
  时不消费末页哨兵，免得落点被吞掉后无重跑机会。向前进
  下一章仍落章首，上一章/下一章按钮、音量键、目录、书签
  的落点语义都不变；同章内改字号/行距/转屏仍按偏移保持位置。
- 阅读设置改底部面板：195 的居中大弹窗改回底部面板，贴底
  悬浮、最高只占屏高 45%、无遮罩，正文区全程可见，字号/
  字体/行距/背景一点就实时变，不用先关面板再看效果；内容
  超高时面板内滚；完成/取消都在面板底行，返回键同样关闭。

## 核对（没动功能）

- 落点改动只影响换章那一刻的定位权归属，进度保存、书架
  派生、目录、书签、净化规则、亮度、音量键翻页的逻辑一个
  没动；滚动模式（上下滚动）的落点仍走 240 那套。
- 设置面板只是换了容器，里面显示/阅读/管理三组选项、
  步进器、胶囊、亮度、净化规则入口一个没少没改。
