# v0.176.0

本版含未单独交付的 v0.175.0（播放失败自动换线路后详情页显示跟随），
175 构建未发链接前被本版取代，不用装两次，线路跟随修复在本版里一起验。

## 直播页顶部栏整行去掉，播放器直接贴顶

- 之前直播页顶部有一行 48dp“直播”标题栏（搜索/收藏/刷新/设置四个图标），
  播放器被压在它下面。现整行去掉，播放器就是页面第一行，只留系统状态栏
  高度（时间、电量那行不压播放器），对标 DS 直播页播放器贴顶的样子。
- 横屏全屏时本来就没顶栏，行为不变。

## 顶栏功能不删，全部移位（用户纠偏：功能保留，只去卡片/顶栏）

- 搜索、收藏、设置 → 节目卡右侧三个图标（对标 DS 频道头齿轮+爱心）：
  放大镜点开原来的频道搜索行，星标收藏/取消当前台，齿轮打开直播设置弹层。
- 刷新 → 直播设置弹层右上角刷新图标（对标 DS 设置弹层右上角刷新），
  点它仍是原来的订阅刷新，失败/未解析提示不变。
- 收藏另改 DS 结构：左列分组第一项就是“我的收藏”，和央视频道/
  卫视频道/未分组并列，点它只看收藏的台；无收藏时这一项不出现，
  默认分组仍是原来的首个真实分组（不是我的收藏）。
- 设置改 DS 结构：节目卡齿轮打开底部“直播设置”弹层，标题右上角刷新，
  两胶囊“切换直播源 / EPG 设置”，源单选列表带手动/接口标签，
  顶部有“切回接口默认直播源”；EPG 胶囊里填全局节目单兜底地址
  （保存/清除和原来管理页同一套）。订阅的增删、导入本地、
  手动加频道仍走原“直播订阅管理”整页，弹层底部给入口，不重复造。

## 书架不动

- 书架仍在底部导航（首页/直播/书架/音乐/设置），本版没动书架页；
  用户说的“主要是书架”若是指书架也要移位，请在推之前纠正，
  本版按“书架原地不动”做的。
