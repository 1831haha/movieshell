# v0.220.0（2026-10-25）

修找书页快速连点加入书架丢书（连点三本，一两本加入失败）。

## 根因

写盘本身有锁，不是写丢的，是入架前的目录拉取在连点时先垮了：

- 入架拉目录没走限流：搜书和追更检查都走搜书/追更共用的 Semaphore(4)，
  入架是直调 chapters，快速连点等于对站方齐发请求（代码注释里自己写过
  齐发被反爬封 IP）；日志里同一时段已有站方 IO 异常重试的记录。
- 拉目录失败一次就判死刑：单次请求非 2xx（如被限流）直接判空，IO 异常
  靠拦截器重试 3 次后仍挂也判空，界面只剩一句“加入失败”，用户只能
  手动重进重点。

## 修复

- 入架拉目录改走统一限流（withSearchThrottle，与搜书/追更同 semaphore）。
- 空结果 1 秒后重试一次，两次都空才判失败。
- 忙状态由单槽位改成集合：连点多本时每本各管各的“加入中”，先点的那本
  不再被后点的顶回“加入书架”（找书页、发现页、发现聚合页三处读取点
  一并改掉）。
