# v0.155.0

> 状态：版本档案 ｜ 日期：2026-10-22 ｜ tag v0.155.0

## 修复

- 字幕设置面板横屏铺满全屏、关不掉：横屏全屏时屏高只有约 360dp，旧面板（标题+400dp 内容+按钮）要 520dp 以上，底下取消/保存被裁到屏外、遮罩也很难点到。现内容区按屏高算上限（竖屏仍封顶 400dp 不变），卡片总高不再超屏，按钮始终可见；标题行右上角常驻关闭键，不用再去底下找取消、也不用硬点遮罩。
- 字幕面板收紧：间距、颜色圆点（36dp→28dp）收小，整体更精致；该改动走播放器内所有共用该卡片的面板（字幕、定时关闭等），不只字幕一处。

## 详情页重排

- 最顶上那一栏整个去掉：标题、追剧、分享不再占一栏；播放器没起来时（只有封面）左上角留一个悬浮返回箭头，播放器起来时它自带返回，不重复盖一层；系统返回手势仍可用。
- 简介卡片重排：海报单独放左列（72×100dp），下面一排小图标：收藏、分享、追剧——顶栏右边那两个功能收进这里，收藏不再挂在卡片右上角；剧名只放一行在图右，下面是集数/年份/地区和源胶囊，整体更简洁。
- 其余不变：主演、简介、复制链接/下载/刷新/字幕、选集逻辑都不动。

## 说明

- 本版只做字幕面板这一件；此前提出的直播源失败自动切下一个源，仍等用户在 154 验完后拍板，不混进本版。
- 日志里 CCTV1 那条在 12:06 仍是老样子（Media3 报 HTTP 错误、libmpv 起播约 5 秒未出画面后失败），与此前结论一致：那台服务器本身不通，本版不对它做盲改。
