# v0.174.0

本版含未交付的 v0.173.0（直播刷新闪退修复），173 构建未发链接，
直接由本版取代，不用装两次。

## 删直播管理页 11 条一键导入入口

- 删掉直播订阅管理顶部的“一键导入稳定直播源（11 条）”大按钮
  及配套的 StableLiveSources 清单（用户纠偏：本地导入本来就有，
  不需要这个定制入口）。
- 已导入的订阅不动：之前经该按钮导入的源仍在下面列表里，
  想清掉的点每条右侧垃圾桶逐条删，删后 App 不自动补回。

## 直播管理页三按钮不再换行

- 之前“导入本地 M3U”（7 字）、“手动加频道”（5 字）在三分之一宽
  的按钮里被默认内边距挤成两行，截图里“手动加频/道”断行很难看；
  “添加订阅”四字本来就是单行。
- 改法：三按钮统一四字——“添加订阅 / 导入本地 / 手动添加”，
  单行齐平。点开仍是原来的本地 M3U 文件导入、手动添加频道弹窗，
  含义没变。

## 首页换源胶囊长按刷新当前源

- 首页顶栏换源胶囊：点按仍是打开换源表；长按直接刷新当前源，
  走首页下拉刷新同一入口（force=true，绕过失败退避），不用再
  下拉整页。刷新时状态环转黄、顶栏刷新指示出现，和下拉刷新一致。
- 未选源时胶囊显示“选择站源”，长按没源可刷，改为打开换源表，
  避免长按无反应。

## 待真机验

- 直播管理页顶部不再有 11 条按钮，三按钮单行齐平，导入本地、
  手动添加点开功能正常。
- 首页换源胶囊点按换源、长按刷新当前源且内容更新；未选源长按
  打开换源表。
- 173 项：含死源的订阅列表刷新不再闪退，提示点名失败源及原因。
