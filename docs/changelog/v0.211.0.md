# v0.211.0

- 全仓精致化：系统原生提示、开关、滑杆、下拉菜单全部换成 App 自家样式，不再是系统灰块、系统紫开关、白底方角菜单。
- 提示：226 处系统 Toast 全部改走统一精致提示——深底 + 香槟金微光描边 + 青色圆点，悬在底部导航上方，不再盖住列表最后一行；点一下可提前关闭；App 在后台时仍回退系统提示，不丢消息。
- 开关：18 处改青色开关（开是青色、关是灰蓝、拇指恒白），跟底部导航选中色同源；阅读器滑杆改青色轨道 + 白色拇指；5 处下拉菜单改毛玻璃底 + 20dp 圆角。
- 找书页：结果卡片补上封面（有封面显示封面，没封面用书名首字占位），标题和作者各只占一行、超长用省略号，加入书架按钮改统一按钮样式；列表底部留空，最后一行不再被导航栏盖住；搜索框聚焦时描边变青色。
- 书架长按直达书籍详情：列表和网格长按不再弹操作表，直接进书籍详情；详情按截图重做——大封面居中、蓝色标签、图标信息行（作者/来源/最新/分组/目录/收藏/净化规则）、右侧蓝色小钮、底部左灰删除右蓝阅读各占一半；分组显示真实分组名（没有就是未分组），最新显示本地目录最后一章的真实标题，收藏切换留在详情里不关页；全选改走顶部菜单“书架管理”。字数/分类/状态/人气这类没有真实数据的标签不编。
- 阅读页去重重做：底栏删掉“界面”（和“设置”开的是同一个面板），只剩目录/设置；正文右侧三颗紫色悬浮钮全拿掉，书签只留顶栏一个图标（列表里已有添加当前进度），亮度只在设置里调；设置卡片收紧——行距、胶囊、步进器都改小，删掉设置里的“章节”一行（底栏已有上一章/进度/下一章/目录），只剩显示/阅读/管理三组；设置顶部的预览不再是写死的“山重水复疑无路”，改成当前章节正文第一段，在哪本书打开就显示哪本书的字。
- 书架下拉刷新逐本状态：以前只在顶部有一行“正在检查更新…”，哪本查完、哪本没查到都看不出来。改成每本书后面自己带圈圈：在线书刷新时行尾转圈，查完一本停一本，有更新立刻出数字角标，查不到的停下来贴红色“失败”；本地 TXT 不联网，永不转圈。网格视图同理，封面中央转圈、失败贴红标。
- 阅读进度滚动模式自动保存：以前上下滚动时进度只在退出阅读页那一刻存一次，App 被划掉或崩溃就丢回上次切章的位置。现在滚动一停就存，和翻页模式的翻页后自动存对齐；切章、退出时照旧也存。
- 说明：截图里那条“如漫画：激活验证错误，请在 XH 发布页订阅源激活”不是 App 自带的提示，代码里搜不到这句话——那是“如漫画”这个源/站点自己的激活门槛，App 绕不过、也不该绕：要么去它的发布页订阅激活，要么在书源管理里关掉/删掉这个源，换别的源搜，提示就没了。
- 小说三路自查·数据丢失批：三路自查（读代码、逐屏对照、正常/异常/边界走流程）后先修最要命的一批，全是会丢数据、会写错数据的：重复入架不再用空目录覆盖已缓存正文；书源改地址或 PY 重命名时，书架上用旧 key 的书跟着迁，不再静默断源，删源确认里会写明有几本书在用这个源；书源文件里一个坏条目不再让整表变空；追更匹配不再兜底取第一条（同名书不再把别本书目录写进来），作者也参与比对；角标改为累加未读存量，检查逐本随查随写盘，中途退出书架不再丢已查完的结果，后台追更的失败也会同步进失败页签；详情目录点某章直达该章，详情内换源后目录和最新重拉，换源对齐结果写进进度，新目录变短时进度钳制到末章并清旧角标；进度保存加锁串行化，损坏时先从备份恢复，退出保存不再绑在会被销毁的组合作用域上，滚动恢复改用真实每行字数和行距换算，不再逐轮漂移；删书失败不再谎报已删除，点开书清角标导航后仍能写完。
