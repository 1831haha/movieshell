# v0.196.0

小说板块按阅读（Legado）重做，196 的零散改动并进本版。

- 书架内搜：搜索框上移到与“找书”同一行（标题 + 胶囊框 + 取消一行排开），框直连活动级搜索 VM，回车即搜；找书页内不再重复画框。
- 书架：顶行改阅读式页签（全部 / 更新失败，失败 id 由追更检查回传并持久化）；列表行改 plain 行 + 底部分隔线，进度条去掉，信息为书名 + 作者 + 已读章节 + 共几章，未读角标改纯数字；右上角菜单为更新目录 / 添加本地书籍 / 书架管理 / 书架布局 / 书源管理。
- 书源列表：顶部搜索框按名或地址过滤；批量模式 + 底部全选（带已选数）/ 反选 / 删除栏（删前确认）；卡片改 plain 行 + 分隔线，行上有开关、测试、编辑、删除；点行 JSON 直接进编辑，长按也能编。
- 长按书源可编辑（仿阅读书源列表）：JSON 改名称 / 地址 / 分组（地址变了 key 跟着变，撞已有地址会拒绝）；PY 重命名文件（只改名不改内容，启用标记跟过去、清桥缓存）。
- 书籍信息页：封面放大 + 蓝色标签（共几章 / 已读进度）+ 作者 / 来源（换源）/ 最新 / 分组（设置分组）/ 目录（查看目录）/ 净化规则（管理）信息行 + 简介；底部为删除书籍 / 阅读。
- 阅读页底栏：上一章 / 进度条（拖动跟手、松手跳章）/ 下一章 + 目录 / 界面 / 设置；右侧悬浮钮书签 / 亮度 / 刷新。
- 阅读设置面板沿用 196 紧凑版（一页显示全部，不滚动；字号与亮度为圆形加减步进器，其余为胶囊），界面与设置目前同指该面板；朗读按用户定不做，章内搜索、添加网址、远程书籍、缓存导出、导出导入书单、日志暂无对应功能，不摆空壳。
