# v0.245.0（2026-10-27）

阅读页去重、更多字体背景、弹窗跟阅读背景走、进度条改细。

## 去重：悬浮钮整体删除

- 左下悬浮白圆钮整组删掉：搜索、刷新只留顶栏，夜间只走
  背景档里的夜间黑/深灰/墨绿，不再留第二条夜间入口。
- 悬浮钮压正文左边缘的问题随之消失，不用再调正文边距
  去迁就它。
- 界面、设置两个面板的取消按钮也删了：设置是改动就立刻
  保存，取消和完成做的事完全一样（都是关面板），只留完成；
  返回键同样关闭面板。

## 更多字体：5 种变 8 种，不打包字体文件

- 新增细体、紧凑、中粗三档，走 Android 系统字体名
  （sans-serif-light / condensed / medium），用 FontFamily
  包系统 Typeface 实现，APK 不因此变大。
- 旧的 5 档 ID 不变，老用户选的字体升级后不串档。
- 注意：中文字形在部分机型上可能回退到默认中文字体，
  紧凑档对中文的差别可能不明显，以真机为准。

## 更多背景：5 档变 11 档

- 新增雾蓝、暖灰、深灰、樱粉、淡紫、墨绿 6 档。
- 雾蓝 #DCE8EF、暖灰 #D8D4CA、樱粉 #FBE9EC、淡紫
  #E9E4F3 是浅色；深灰 #20242B、墨绿 #1E2B26 是深色。
- 旧的 0 到 4 号档位含义不变，跟随系统档仍按系统深浅算。

## 弹窗和面板：跟阅读背景的黑白走，不跟系统主题走

- 之前的问题：阅读背景是夜间黑、手机系统是浅色时，界面
  面板和弹窗还是白的，因为它们跟的是系统主题。
- 现给通用弹窗加可选的强制深浅参数，只阅读页传：目录、
  书签、章内搜索、换源四个弹窗和界面、设置两个面板，都按
  阅读背景的实际深浅出深底或浅底；其他页面的弹窗不动，
  仍跟系统主题。
- 深色弹窗底 #171B28、主字 #E8EAF0、次要字 #B0B7C3；
  浅色弹窗底白、主字 #242424、次要字 #666666。

## 进度条：细轨道 + 轨道上小球

- 根因已核实：Material3 1.3.1 的默认 Slider 就是 16dp 粗
  轨道 + 4×44dp 竖线滑块，截图里那根竖线和末尾圆点都是
  它自带的，不是咱们画的装饰。
- 现改走 SliderState 自定义 thumb/track：轨道 4dp、无刻度、
  无末尾圆点，滑块改成 12dp 圆球居中在轨道上。
- 语义不变：滑杆仍是本章进度，拖动只跟手、松手才定位，
  不跨章；没拖动时滑块跟视口滚动进度同步。
