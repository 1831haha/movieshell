# v0.221.0（2026-10-25）

两处界面修。

## 播放器右下角“自动”被裁一半

第二行控制栏一共 9 个按钮（播放、上一集、下一集、倍速、选集、顺序播放、
自动、引擎、全屏），普通 Row 在窄屏上放不下，尾巴上的“自动”、引擎、
全屏直接被推出屏外，只剩“自动”半个边露在右边缘，点它弹“当前为自动
清晰度”。

修：第二行改横向滚动。宽屏能放下时 weight 占位仍把全屏顶到右边缘；
窄屏放不下时整行可左右滑动，每个按钮都点得到。进度条那行不动。

注：“自动”本身是清晰度占位按钮——当前直链没有多清晰度可选，所以
只有自动这一档，点它就是提示当前为自动清晰度；这版修的是它被裁掉
看不见的问题，不是多加清晰度档位。

## 找书框留着上次搜的词

找书框绑的是活动级搜索 VM 的 keyword，切 tab、切页 VM 也不销毁，
回找书页框里还留着上次的词。

修：找书页离页时清掉 keyword。只清框里的词：搜索历史（框下方历史
记录）不动，已搜出的结果也不动。独立找书页与书架内嵌找书共用同一
个屏，两处宿主离页都会走到这个清理。
