# v0.200.0（2026-10-24）：JS 书源引擎补齐第一批

0.199 的 JS 引擎缺口补了三件；发现页、Cloudflare 网页验证放下一批（见末尾）。

## 新能力

- **jsLib**：BookSource 新增 jsLib 字段（阅读式共享 JS 库），每次规则求值前自动前置；URL 形式的 jsLib 暂不支持（返回空，不影响规则本身）。
- **源变量落盘**：SourceVariableStore 在 App 启动时从 filesDir/novel_source_vars.json 读回，set 时同步落盘。重定向域名记忆不再随 App 退出丢失（999 这类站重启后不用重新探测）。
- **详情封面 JS**：NovelSourceEngine.detailCover()——ruleBookCover 含 `<js>` 时跑 Rhino（JS 里的 {{book.name}} 等模板已替换），余下可接 JSON 路径；纯 CSS 封面规则也走这条。入架时搜索结果封面为空才调用（只多一次详情页请求），已有封面不受影响。
- **规则模板替换**：evalTextRule / evalListRule / evalNextUrls / runLoginCheck / 正文 JS / 正文替换 JS 入口统一做 {{book.name}} / {{book.bookUrl}} / {{book.author}} / {{chapter.title}} / {{chapter.url}} / {{title}} 替换；JsCtx 新增 bookAuthor，book 对象 author 不再写死空串；目录求值 ctx 也补了书名/地址/作者。

## 未动

- 老纯 CSS 源走原路径逐字未动；0.199 的 Cloudflare 占位（startBrowserAwait 返回空）仍在。
- 下一批：发现页（ruleExplore 字段 + 书架子结构内入口 + 分类屏）、Cloudflare WebView 验证（验证通道 + WebView 屏 + Cookie 同步）。
