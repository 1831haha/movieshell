# v0.212.0（首页点播自查优化批）

## 修掉的流程断点

- 分类加载粘滞：规则真返回空时，收集器见目标为空又把 loading 置回，整屏骨架屏一直盖着。改按“有没有缓存条目”区分：有条目（哪怕空列表）就展示空态并停转圈，没条目才转圈。
- 分类失败抹掉好缓存：失败原来仍写空列表进内存缓存；失败现在只标失败态、不碰缓存，切走再切回仍能秒回旧内容。
- 分类收尾漏清 loading：finally 原来只清 isLoading，从不碰 loadingCategoryId；最新请求收尾时一并清掉本分类的 loading。
- 离页中断后长期黄灯：首页加载被取消的分支原来不走应用结果，isLoading 没人清；取消分支现在清掉。
- 下拉刷新拽回分类 1：下拉和首次加载共用 resetSelection，成功就回分类 1，且推荐一失败当前分类根本不刷；下拉现在保持当前分类，完事后只刷当前分类。
- 筛选迟到污染：筛选组请求原来无世代／无源校验；只认发起时的世代与源 key，对不上丢弃。
- 详情刷新抹页：网络一抖就把整页写成 null、播放打断；刷新失败保留旧内容、只提示，首次加载失败仍走失败态。
- 海报滚动位置丢失：普通 remember，详情返回／切 tab 后每次回顶；改用 LazyGridState 官方 Saver 存进 SaveableState，返回恢复位置。

## 界面精致化

- 加载中与空态同屏：空态现在只在加载结束且确实无数据时出现。
- 海报片名浅绿块：写死的浅绿底＋深绿字改成跟卡片同款毛玻璃底＋微光描边，字色跟主题走。
- 海报图裂空白：失败后回落标题首字占位。
- 备注彩虹渐变＋跑马灯：改单色青色＋省略号。
- 筛选行无组名：组名固定在行首不随横滑走。
- 副标题只有年份：改成“年份 · 分类”两段式。
- 继续观看：时长未知不再写“看到 0%”，只显示集数；进度条显式指定青色；空 url 老记录改用 vodId 兜底去重。
- 换一换：原来只是循环移位；改按种子真随机洗牌，换批即回顶；空 vodId 去重键同样用标题兜底；海报映射按列表缓存，不再每次重组重算。

分类／推荐分页、详情路由无源信息、分类以位置序号为键、首页缓存读改写竞态、删源后缓存孤儿、禁用源详情仍可播、非 drpy 下拉假刷新、换源胶囊灰环与换源弹窗排列轮换，见《首页点播自查报告》。
