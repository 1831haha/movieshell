# v0.158.0

## 改动（对标 DsPlayer 直播界面，含 157 的详情页改动）
- 直播页内换源：节目卡下方加一排换源条——全部 + 各直播源（M3U 订阅名 / live 插件文件名 / 手动添加），点一个只看该源的分组和频道，切源自动播该源第一个频道；点全部回到聚合。
- 播放失败自动切同名源：直播播放最终失败时（播放器内同内核重拉 2 次、换内核都走完之后），自动切下一个同名源，提示“当前源播放失败，已自动切到源 N”；同名源都失败才提示“同名源均播放失败”。切到其他源时换源过滤自动放回全部，避免列表与在播频道对不上。
- 节目单全局兜底：直播订阅管理里新增“全局节目单（兜底）”，填 XMLTV 地址后，本源无节目单时用它查正在播 / 下一档；.xml.gz 压缩包尽力解压解析，解析失败显示暂无节目数据。无节目单来源时节目卡提示去订阅管理里填全局地址。

## 说明与已知限制
- 线路条数取决于直播源本身带几条：右列只显示已有的同名频道，不去扒 DsPlayer 的源单，DsPlayer 日志里那 7 条 CCTV1 线是它那个源自带的，不会原样搬进壳子。
- 全局节目单不内置任何源，地址由用户自己填；填了也不保证每个频道名都能在节目单里匹配上，匹配不上仍显示频道名。
- 本版包含 157 的详情页主演、简介移到海报右边、简介 12sp，157 单独的包不用再等。
