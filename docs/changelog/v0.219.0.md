# v0.219.0（2026-10-25）

修切 tab 后直播还在后台响。

## 根因

直播页里嵌的是 `PlayerScreen(embedded=true)`，嵌入模式的退出故意不清引擎——因为跳全屏独立播放页是同一会话的延续，清掉会断播。但切 tab 时直播页同样被 dispose，走的也是这条“不清”路径，播放器单例没人停，声音就留在后台了。

## 修复

照详情页 `goingFullscreen` 的套路给直播页加同款开关：

- 跳全屏独立播放页、进直播管理页是页内跳转，先置开关，dispose 时跳过停播，会话延续；
- 其他离开路径（切 tab 等）开关为关，dispose 时停引擎、清会话、关播放器可见标记；
- 开关是 plain remember，不随 saveState 恢复，回直播页重组自动变回关，不用手动复位。

回直播页后按选中频道重新起播（直播无进度可续，本来就是从头播）。
