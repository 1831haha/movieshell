# v0.197.0

- JSON 书源搜索支持 POST：searchUrl 可带阅读式选项后缀 `URL,{"method":"POST","body":"...{{key}}...","charset":"GBK","headers":{...}}`；body 里的关键词按 charset 编码（如 GBK 站），返回页面沿用 UTF-8/GBK 自动识别。没有后缀的老源走原 GET 逻辑，不受影响。
- 由此，之前给阅读 App 的第一版主 JSON 源（GBK 的 POST s.php）现在也能直接导进侠影搜书；详情/目录/正文仍走 GET，不受影响。
- 不在本版：目录与正文的分页跟随（nextTocUrl / nextContentUrl），JSON 引擎目前只抓单页目录与单页正文，长书的目录与多页章节仍以 PY 版为准。
