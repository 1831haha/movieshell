# v0.184.0

换源弹窗源框更明显 + 贴近图 2 风格，首页顶栏站源 pill 收窄。

## 源框更明显，颜色跟随主题

- 原来卡片是毛玻璃底，透过去看不清，改成实色底 + 1dp 细描边，
  圆角改 16dp，卡片一眼就是个框，不再是飘着的字。
- 当前源不再是写死的绿：底色取主题品牌渐变第一色的浅 tint，
  描边还是品牌渐变，换主题色时当前源颜色也跟着变；
  非当前源是实色底 + 细描边，当前源一眼认得出来。
- 关闭改成图 2 那种文字 pill“关闭”，背景也是主题主色浅 tint，
  原来小 X 图标太小、不起眼。

## 搜索框收窄

- 提示改短成单行“搜索站源”，原来那句长提示换两行把框撑高；
  框体改浅灰 pill、去掉描边，贴近图 2；宫格按钮改宽一点写
  “宫格·大卡”，搜索框自然就窄下来了。

## 宫格：点一下换，长按直接选，类型加到 6 种

- 点宫格按钮还是依次换，新增：长按宫格按钮直接打开选择菜单，
  不用一格一格点过去，点菜单里的一项就切过去。
- 类型从 3 种加到 6 种，同一批现在的源原样放进去：
  大卡（2 列）、图标（5 列）、列表、宽卡（1 列大卡）、
  中卡（3 列）、紧凑（小行列表，源多时一屏看得多）。

## 首页顶栏站源 pill 收窄

- 原来站源 pill 用 weight(1f) 填满整行，名字短如“选择站源”
  时 pill 也撑得老宽；改成外面包一个 weight 的 Box 靠右放 pill，
  pill 只按内容宽，名字长时顶到剩余宽度再省略；
  内边距和状态环也同步收了一点，整行更紧凑。

## 待真机验

- 换源弹窗卡片是不是明显了，当前源底色是不是跟着主题色走，
  换个主题再看是不是也变了。
- 搜索框是不是单行 pill、不再撑高，宫格按钮点一下换、长按
  出菜单，菜单里 6 种都能切过去。
- 首页顶栏站源 pill 是不是靠右、按内容宽，名字长时省略不溢出，
  点按还是打开换源、长按还是刷新。
- 本地无编译器，语义仍以云构建为准；双自查脚本已绿。
