# v0.164.0

- pics:// 看图：PY 源 playerContent 返回 `pics://图1&&图2&&…` 时不再进视频播放器，改为全屏看图页——左右滑翻页、底部上一张/下一张、点图显隐顶栏（标题 + 第 x / 共 N 张）。此前壳子白名单里没有 pics，走到视频播放器直接报“地址格式暂不支持”，看图一直进不去。
- 分流点：详情页点章节进看图（返回只关看图、不退详情）；独立播放路由也分流；EngineHost 再加一道拦截，pics 地址绝不进 Media3/libmpv。
- 防盗链：解析链路透传的 Referer/UA 会带给每张图（不带 Referer 的站会 403），走 Coil 官方请求头。

## 已知限制

- 详情页进入仍按视频逻辑自动打开第一章看图（与“进入详情页直接播放”一致），想换章先点返回回到章节列表再点。
- 看图页暂无缩放、长按保存、预加载之外的手势；图特别多（几百张）时按页加载，翻页时才下图。
- 本版只认 `pics://` + `&&` 拼接这一种约定；源返回其他图片协议时仍按原逻辑走。
