# v0.181.0

音乐页顶栏三行并两行，功能一个不删。

## 并行方案

- 第一行：搜索框（仅在线）+ 搜索键 + “歌单导入”（仅在线）
  + “源管理”。非在线时这一行只留右对齐的“源管理”，
  切页签时顶栏高度不跳。
- 第二行：页签胶囊（在线 / 本地 / 收藏 / 歌单）+ 右侧一个
  当前音源小芯片，点芯片就是切换音源，名字过长截断，
  不会把页签挤扁。
- 原 v0.180.0 的音源大卡整行删掉：“当前音源 / 自动”两行字
  收进芯片里只剩源名，歌单导入和源管理挪到第一行，
  切换音源、歌单导入、源管理三个入口都在，只是换了位置。
- 平台行、榜单竖排满宽、搜索逻辑都没动。

## 待真机验

- 在线页顶栏只有两行：第一行搜索 + 导入 + 源管理，
  第二行页签 + 右侧音源芯片，点芯片能打开切换音源弹窗。
- 本地 / 收藏 / 歌单页顶栏也是两行：第一行只剩源管理，
  第二行页签 + 音源芯片。
- 搜索框变窄后输入、搜索键、歌单导入、源管理都还能点，
  页签四个字没被芯片挤到换行或截断。
- 本地无编译器，语义仍以云构建为准；双自查脚本已绿。
