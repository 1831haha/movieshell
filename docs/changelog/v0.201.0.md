# v0.201.0（2026-10-24）：JS 书源引擎补齐第二批——Cloudflare 验证通道

0.199 的最后一个引擎缺口（startBrowserAwait 占位）补上。发现页放下一批。

## 新能力

- **VerifyGate 验证通道**：引擎在 IO 线程调 `java.startBrowserAwait(url, title)` 时挂起等待（最长 180 秒）；界面层 VerifyGateDialog（挂在 MainActivity 根 Box，全局悬浮）弹全屏 WebView，用户手动过验证后点「验证完成」，整页 HTML + 落地 URL + Cookie 回填给引擎，Cookie 写进 OkHttp 共享 Jar，后续请求自动带上；超时/取消返回空响应，规则求值按空结果处理，不崩。
- **cookie.removeCookie 落实**：之前是占位日志，现清掉该 host 在 OkHttp Jar 与 WebView 里的 Cookie（验证重进时不带旧 Cookie，与 999 探索规则的 `removeCookie` + `startBrowserAwait` 链路对上）。
- **不自动判定验证成功**：Cloudflare 形态多变，误判比让用户点一下更糟；按钮在首屏加载完成（onPageFinished）后才可用。
