# v0.215.0：确定项三批（小说／音乐／首页）

本版只做之前三路自查里已经确定、不需要用户再定语义的项；需要用户定的（播放失败是否自动跳歌、
全本小说网长书目录二选一、长按首页 tab 三选一等）一律没动。

## 小说

- 批量换源：书架多选栏新增「换源」，选目标源后逐本在该源搜书名、按追更同款匹配换目录；
  搜不到或目录拉取失败的那本不动，最后报成功／失败本数；换源后在读章标题跟新目录对齐。
- 章内搜索：阅读页顶栏新增搜索入口，本章正文内找词、点结果跳转（滚动模式按恢复同款公式换算像素，
  翻页模式按页首偏移跳页），不跨章。
- 发现页列表行详情预览：点行先出预览弹窗（封面／书名／作者／来源），确认才入架，不再点按即入架。
- 净化规则改动后缓存重拉：净化规则页新增「清除已缓存正文」，目录和进度不动，清掉的章节下次打开
  重拉并走新规则；原来规则改了、已缓存章节一直是旧样子。
- TXT 导入三修：同一文件重复导入不再产生两本同名书（按本地书名判重、提示跳过）；GBK 回退修好
  （旧写法 UTF-8 非法字节从不抛异常，GBK 回退是死代码、中文 TXT 全读成乱码）；首章与后续章切分
  同口径（标题行都要求 ≤40 字）；导入失败原因分开说（读不到文本／已在书架／保存失败）。
- 角标样式统一：列表与网格更新角标同款——数字 pill、主题 primary、无「+」、不再呼吸脉冲
  （多本更新时满屏闪已去掉）。

## 音乐

- 队列行内删除与清空：播放列表弹窗每行可删（删当前歌停播，其余修正下标并持久化），顶部可一键清空。
- 迷你条进度与关闭：迷你条底部加进度条（读播放器 position/duration），右侧加关闭钮（停播并清掉迷你条）。
- 导入新源自动切：本地 .js 导入与 URL 添加成功后，新源直接设为首选——原来只追加到注册表末尾，
  按顺序轮询可能长期轮不到。
- 睡眠定时单例拆分：视频与音乐各用一条独立定时（VideoSleepTimer／MusicSleepTimer）——原来共用一个单例，
  音乐定了时、再进视频一定时就把音乐的顶掉（反之亦然）。
- Cookie 过期引导：解析失败原因里带登录／过期／Cookie／验证字样时，提示指路到音源管理补 Cookie，
  不再静默降级成一句「请重试」。
- 列表时长：搜索结果本身不带时长，播过的歌才有时长——播放器记下播过歌曲的时长（持久化），
  列表行以 chip 显示；没播过的歌不编时长、不显示。

## 首页

- 分类分页：分类视图底部加「加载更多」，下一页追加（按 id 去重），空页显示「没有更多了」；
  切分类重置分页，无筛选时合并后落盘；推荐视图不分页（推荐流本身没有分页口）。
- 失效源不毁当前激活态：drpy／PY／PHP 的 setActiveRule 先验规则文件存在再动当前态，返回是否成功；
  继续观看点到已删源时不进详情页、不动当前源，只提示「该记录的源已删除或不可用」；订阅站源找不到同样不进页。
- 删源缓存孤儿：删源时同步清首页缓存（推荐＋分类）；HomeCache.clear 原来只删主文件，
  分类缓存文件全留成孤儿，现一起清。
- 禁用源详情仍可播：详情页点播前查禁用表，禁用的源不解析、只提示「该源已禁用」。
- 非 drpy 下拉假刷新：无源时下拉原来空转 1.2 秒假装刷新，现直接收指示条并打开选源（与长按首页 tab 无源时同口径）。
- 继续观看来源名与删除：卡片加「来源：源 key（去扩展名）」一行；卡片右上角加删除钮（删单条，不用去历史页清全部）。

## 本轮没动的

- 需要用户定的：播放失败是否自动跳歌；全本小说网长书目录二选一；长按首页 tab 三选一；
  音乐切源语义统一；歌单侧删歌是否联动播放器；探源助手提案。
- 需真机复现的：Cookie 弹窗连开两源迟到覆盖；服务被杀后 controller stale；本地导入 id 撞车。
- 精致度小项（下一批再排）：音乐金色口径两套、音质徽标色重复、榜单四色写死、长列表回顶、历史词删除钮、
  FAB 毛玻璃、分组头分隔、播放模式无文字、禁用源测试按钮未置灰、无歌时换源／定时仍可点、音质 chips 横滑；
  首页分类以位置序号为键、HomeCache 读改写竞态与 key 截断撞车、换源胶囊灰环与弹窗排列轮换、
  筛选行 LazyRow 化、骨架屏形状、HomeLoadGate 旧 key 清理；小说书架菜单远程书籍／添加网址／缓存导出／
  书单导入导出、书架与阅读器进度定义两套、翻页不能滑动跨章等低项。
