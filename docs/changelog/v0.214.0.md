# v0.214.0（小说贴近阅读界面对齐批）

## 书架行章节标题（报告第 13 项）

- 列表行：已读行补在读章节标题（“已读：第 X 章 · 标题”），共章行补最新章节标题（“共 N 章 · 最新：标题”）；网格卡片书名下补“最新：标题”一行。
- 数据口径不另外发请求：最新标题由入架／换源／追更写目录时写进书索引，在读标题由阅读器五路落盘时写进进度；老数据无标题时回落只显章号，不编假标题。

## 发现聚合页（报告第 14 项）

- 书源管理新增“发现聚合”入口：顶部筛选框（筛已抓到的书名／作者）、下方按源分组（源名标题＋分类 chips＋横滑书行），切分类只重抓该源，点书走现有入架流程，每组右上角可进该源单源发现页。
- 只聚带发现分类的已启用 JSON 书源；PY 源没有发现分类体系，不进聚合；某源抓空时给重试，不谎报。

## 书源字段编辑器（报告第 15 项）

- ✎编辑从三框（名称／地址／分组）改成六页签表单：基础／搜索／详情／目录／正文／发现，每格带字段 key 提示（如 ruleSearch.bookList、{{key}} 按 UTF-8、replaceRegex 每行一条 ## 分隔）。
- 保存走整条 JSON 回写（字段全量 round-trip，地址变了自动迁书架上的书）；想改整条 JSON 仍走长按文本编辑。

## 中项入口

- 多选栏加“反选”（只对当前可见书取反）。
- 详情页加单本“追更”开关：关掉的书手动检查与后台追更都跳过，拨动即写盘。
