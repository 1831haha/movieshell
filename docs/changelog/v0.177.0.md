# v0.177.0

接 176 的直播页顶栏去掉，音乐页和书架页的顶部标题栏也去掉——
176 只做了直播，是因为当时用户只点了“直播页顶部那行”，
书架那句没吃准不敢一起做；本版把剩下两页补齐，功能都不删。

## 音乐页：顶部“音乐”标题栏去掉

- 搜索框（在线页签）/页签胶囊直接贴顶（仅留状态栏高度），
  上面不再有“音乐”标题和渐变线。
- 原标题栏三个功能移到页签下方一排右对齐小按钮，无标题、无渐变线：
  切换音源（图标+文字）、歌单导入（仅在线页签，和原来一样）、
  音乐源管理。弹窗与导入逻辑零改动。

## 书架页：正常模式顶部“书架”标题栏去掉

- 阅读数据条（今日阅读/本周章节/连续打卡）直接贴顶（仅留状态栏高度），
  上面不再有“书架”标题和渐变线。
- 原标题栏五个功能移到数据条下方一排右对齐小按钮，无标题、无渐变线：
  添加书籍（下拉仍是添加本地书籍）、检查更新、批量管理、
  找书、书源管理，逻辑零改动。
- 多选模式的“已选 N 本”标题栏保留——那是批量操作的操作栏
  （全选/删除/分组/取消），不是正常顶栏，去掉它就没法批量操作了。

## 待真机验

- 音乐页打开就是搜索框/页签贴顶，没有“音乐”标题栏；
  页签下方切换音源、歌单导入、源管理都能点开。
- 书架页打开就是数据条贴顶，没有“书架”标题栏；
  数据条下方添加、刷新、批量、找书、源管理都能用；
  点批量管理进多选后“已选 N 本”栏还在，全选/删除/分组/取消正常。
- 本地无编译器，语义仍以云构建为准；双自查脚本已绿。
