# v0.222.0（2026-10-25）

修直播页切 tab 时的重影。

## 根因

不是旧页面残留，是切 tab 那 300ms 的淡入淡出过渡帧：全局转场是
新页淡入 + 旧页淡出同时进行，300ms 内两页以透明度混合共存，新页
看起来 dim、旧页频道列表透出来；播放器用的 SurfaceView 不跟透明度
走，过渡时视频帧一直全亮，残影显得更亮。2 秒后过渡结束、旧页销毁，
重影自行消失（用户已确认）。

## 修复

只改 tab 切 tab 的退出混合：转场 lambda 里判断正在退出的页与要进入
的页两边都是 tab 目的地（首页、直播、书架、音乐、设置，含经底部外
入口到达的找书）时，退出混合置空——旧页瞬间撤掉、新页仍淡入 +
8dp 位移，不再有双页叠在一起的一帧。tab 与子页之间（进详情、管理
等）仍走原转场不动；视频仍走 SurfaceView，不改 TextureView（无谓
的功耗代价）。
