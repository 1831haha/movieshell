# v0.230.0（2026-10-26）

229 真机验的跟进：详情页能打开了，但 999 的书入架失败、作者行重复显示。

## 作者行重复显示

- 搜书结果的作者字段自带“作者：”前缀（999 搜索规则原样带出），
  详情页又有“作者”标签列，叠成了“作者 作者：…”。
- 本版详情页显示前去掉这个前缀，标签＋名字只出现一次。

## 入架失败：目录没拉到

- 229 日志对完：搜书 30 条正常，详情页 GET 大多 200，但站很抖，
  有一本一次等了 22 秒超时，另几本也都在重试；5 本同时点加入，
  并发一多超时更多。
- 关键是目录首抓失败时代码直接判空、连诊断行都没记，日志里
  看不到“目录诊断”，分不清是没抓到还是规则没命中。
- 本版：目录首抓失败重试一次，仍失败记一行“目录首抓失败”
  （带源名和地址），下次再失败凭这一行定真因，不用再猜。

## 日志噪音

- 离开详情页时取消抓取，被当成“详情抓取失败”记了一笔，
  本版取消不再记，只记真正的抓取失败。

## 封面占位字

- uaa001 封面接口本身时好时坏（229 日志里重试耗尽一次、后来
  又 200），加上离开页面取消了抓取，不是规则 bug，本版随入架
  一起验。

## 技术点

- SearchBookDetailScreen：作者显示前 strip“作者：/作者:”前缀。
- NovelSourceEngine.bookDetail：runCatching 里原样抛出
  CancellationException，取消不再走失败日志。

  仍 null 记“目录首抓失败”诊断行后返回空。
