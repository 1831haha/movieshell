# v0.192.0

只做两件事：插件目录不再被相册收成假视频；聚合搜索改左右分栏。配合插件市场 magnet-stream 1.0.6 一起用。

## 根因

- magnet-stream 1.0.5 的 node_modules 里有 98 个 `.ts` 文件（96 个 `.d.ts` 类型定义 + 2 个源码 `.ts`，运行时只用 `.js`），安卓把 `.ts` 当视频格式（MPEG-TS），相册里凭空多出一堆 0 秒空白“视频”。用户截图里那个文件（xmlbuilder/typings/index.d.ts，6.05KB）与包内同名文件 6055 字节对得上。
- 包里没有任何 `.nomedia`，侠影装插件时也不会写，系统扫描时没把插件目录排除在外。

## 改法（App 侧）

- `StoragePaths` 新增 `.nomedia` 单一入口：`ensureNomedia(dir)`（目录存在且文件缺失时写一个空 `.nomedia`，写失败吞掉、不让安装/启动因为一个标记文件失败）与 `ensureNomediaForPluginDirs(context)`（公开侧 plugins/、service/ 根目录 + 每个已装插件子目录各写一个，根目录挡整棵树、子目录是双保险；私有 filesDir 下的 runtime/pylibs 本来就不进媒体扫描，不碰）。
- 两条安装路都落盘后写：市场安装的 server 分支（`PluginMarket.installZip`，swapDir 后）与服务页本地 zip 安装（`ServicePluginManager.install`，swapInstallDir 后）。
- 启动时后台补一次（`XiaYingApp.onCreate` 里 IO 协程、失败吞掉、不阻塞启动）：光靠安装时写，2026-10-23 之前装好的旧插件还是漏网。

## 改法（市场侧，magnet-stream 1.0.6）

- 包内去掉全部 98 个 `.ts` 文件；补两个 `.nomedia`（包根 + magnet-stream/ 子目录）；plugin.json 与 server.json 版本号都同步到 1.0.6（此前 server.json 还是 1.0.4，与市场 1.0.5 不一致的老问题顺带修掉）；包改用压缩，体积从 33MB 降到 9.3MB（size 9316226，md5 83f659f36b0e78d63ec0247eeeed53df）。
- market.json 条目、README 条目表、updatedAt 同步更新；check_market.py 全部通过；按市场惯例旧包 1.0.5.zip 已从 packages/ 移除（git 历史里还在，可回滚）。

## 聚合搜索左右分栏（v0.192.0 追加，未推前并入本版）

- 搜索结果页改成左栏源列表 + 右栏视频网格：左栏 120dp 窄列，只放源名和状态，不挤右栏海报；右栏双列网格，海报 + 片名，全部混排时片下带源名，单源时源名已在左栏、不重复写。
- 左栏按配置原顺序列出本次目标站（不是先到先跳的顺序），跑完的显示条数、没跑完的显示“搜索中…”；点左栏切右栏，点“全部”回混排（分组仍先到先出）。页顶加“已搜 X/Y”进度（Y 是本次目标站数，黑名单跳过的源不计在内，仍走原有“X 个源响应慢已跳过”提示）。
- 为此流式搜索改发全部完成态：空结果也发一个完成事件，调用方只计已搜数与左栏状态、不进展示列表，否则没结果的源会永远停在“搜索中…”；演员作品页未动，仍用一次性 searchAll。
- 旧的纵向“分组头 + 大卡片列表”本版起不再用于搜索页；只搜当前源时同样是这套分栏（左栏只有“全部”+ 当前源一条）。

## 已知限制与待真机验（须说清，别让用户以为装完立刻干净）

- `.nomedia` 只挡以后的扫描：已经进了相册的条目不会因为多了个标记文件就立刻消失，要等 1.0.6 更新把旧 `.ts` 文件删掉、再重启手机触发一次媒体扫描后才会跟着消失。
- 别在相册里批量删这些假视频：相册删除会真删插件文件，服务会被弄坏。
- 待真机验：装 0.192.0 后启动一次，xiaying/plugins/、xiaying/plugins/magnet-stream/、xiaying/service/ 下是否都有 .nomedia；市场更新 magnet-stream 到 1.0.6 后，旧 .ts 文件是否没了、重启后相册里假视频是否消失；新装一个 server 插件后其目录下是否有 .nomedia。
- 待真机验（分栏）：搜所有源时左栏是否先列出全部源、跑完的变条数、没跑完的显示“搜索中…”、页顶“已搜 X/Y”是否一路涨到总数；点左栏某个源右栏是否只剩该源的片、点“全部”是否回混排；搜中途点已出现的片进详情是否正常；只搜当前源时分栏是否正常（左栏只有一条）。
