# v0.203.0（2026-10-24）：yt-dlp 通用解析线路

0.202 嗅探/爬虫补齐的下一批：yt-dlp 只做通用提取器，插件形态带入。

## 新能力

- **解析线路新增 type=99（yt-dlp 通用）**：ParseApi 新增分支，调
  ChaquopyEngine.resolveYtGeneric（30 秒超时，桥同步阻塞故沿用独立 scope
  + 超时放行模式，与 callBridge 同款）。
- **插件 yt-dlp-generic 1.0.0**（xiaying-plugins，市场已上架，minApp 0.203.0）：
  yt-dlp 2026.10.21 全量包 + wrapper `yt_generic.resolve(url)`，装后 pylibs
  合并进共享目录，sys.path 已有，无需重启 App。
  - wrapper 域名黑名单先行：youtube.com、youtu.be、twitter.com、x.com、
    instagram.com、twitch.tv（含子域名）在 import yt_dlp 之前就拦截，绝不
    交给 yt-dlp；全量包不裁剪（裁剪会破坏 extractor/__init__ 全量 import）。
  - 选链：顶层 url 优先，否则挑带音视频的最高格式。
  - 插件未装时线路返回空串，不抛异常、不触发 24 小时熔断；装上立刻可用。
- **设置页**：解析线路列表 type=99 显示“yt-dlp”；添加对话框新增“yt-dlp 通用”
  选项，地址栏留空自动填 ytdlp://generic（仅作线路标识）。
