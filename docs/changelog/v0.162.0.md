# v0.162.0

- 搜索慢源提示：同一源连续 3 次搜索超时进本会话黑名单，本会话内不再发请求，结果页显示“X 个源响应慢已跳过”；黑名单不持久化，下次启动还有机会。流式渲染没做，现状仍是收齐后推 UI。
- 图片缓存自动清理：图片缓存超 1GB 时每日空闲清理一次，走 Coil 官方 clear，不直接删文件；视频缓存不自动碰，只走设置页手动清理（先 release 再删）。
- 插件安装全量校验：server.json 带 files 清单时逐文件流式哈希比对，多余、缺失、哈希不符均拒绝；只有旧 sha256/md5 时维持只校验主脚本，存量插件不炸。
- 原生 rtp:// 走 libmpv：与 RTMP 分支同构，未装插件提示去市场，不改用户持久化内核选择；http 形态 udpxy 本来就能播，不动。

## 已知限制

- rtp:// 只在局域网 WiFi 下有意义，蜂窝下播不了属环境限制；未做组播锁与 /status 探活，播了才知道。
- 搜索黑名单在本会话内是粘性的：被拉黑的源本会话内不再被搜，即使它后来恢复，也要等下次启动。
