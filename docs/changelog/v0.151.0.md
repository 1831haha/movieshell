# v0.151.0

> 状态：版本档案 ｜ 日期：2026-10-22 ｜ tag v0.151.0

## 新功能

- 本地 PHP 规则终于能出内容了，走 CLI 引擎：有请求才跑 php，跑完退出，不占端口、不留常驻进程。
- PHP 规则的首页、分类、详情、搜索、播放全通了，批量检测也会真的探一次首页。
- PHP 播放的解析线路和防盗链头走已有收尾，和 PY 规则一致。

## 修复

- 修复了 PHP 规则选中后首页还是空的、详情和播放都走不到的问题。
- 手册里“PHP 只能存不能执行”的旧说法已改掉。

## 已知限制

- 本版 PHP CLI 尚未真机逐项验证：需要手机上装好 php 运行时插件，并把 demo_spider.php 连同 spider.php、HtmlParser.php 放到 xiaying/php/t4_demo/ 目录再验。
- php 插件未安装时 PHP 规则返回空结果，不会假装有内容。
- Node CLI 这版没做：没有可复用的 Android Node 二进制，drpy-node 的手机包是 Termux 方案，不是插件二进制；Node 的 drpys  runner 还要另起调研，不冒充已做。
- RTMP 交 libmpv 播（上一版的 151 候选）顺延到下一版，这版只做 PHP CLI。
