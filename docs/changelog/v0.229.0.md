# v0.229.0（2026-10-26）

搜书结果点书，直接进图 1 那种书籍信息整页。

## 点卡片进详情页

- 之前搜书结果卡片点着没反应，只有“加入书架”钮能点；
  书架里那个详情是弹窗，不是图 1 的整页。
- 现在点卡片（书架内嵌找书、独立找书页都行）进书籍信息整页：
  毛玻璃封面头＋居中大封面＋书名＋类型标签＋信息行＋简介
  （带展开）＋目录＋底部“放入书架 / 阅读”。
- 卡片里的加入书架钮照常点，不触发进详情。

## 详情页里有什么

- 信息行：作者、来源、最新（目录最后一章的真实标题）、目录
  （共 N 章）。状态/人气这类源没给的数据不编假标签，没有
  就不显示那行——书架详情页一直是这个口径。
- 类型标签：源的详情规则里一直有 kind 字段，但引擎解析时
  根本没读它，本版补上解析与回存，标签行才有数据可画。
- 简介：默认收三行，点 [+展开] 看全文，[收起] 缩回去。
- 查看目录：展开章节表，点某章直达该章；目录拉不到时
  显示“加载目录失败”，点查看目录会 toast 并重试（图 1
  截图里正好就是这个失败态）。
- 放入书架：走现在的入架流程，已在书架时按钮变“已在书架”。
- 阅读：阅读器只认书架条目，未入架时先入架再打开；入架
  失败（入架流程自己会 toast）就取消跳转，不擅自进阅读器。
  目录拉不到时点阅读只 toast“目录获取失败”。

## 技术点

- 引擎新增 bookDetail：详情规则（名/作者/简介/封面/类型）
  一次求全，走 detailCover 同款抓取链（fetchPage＋握手后
  重抓，227 的教训）；非 JS 源走纯 CSS 提取。
- 已在书架的书优先读本地目录（跟书架详情页一致），不用
  每次都重新联网拉。
