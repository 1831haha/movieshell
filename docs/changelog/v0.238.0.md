# v0.238.0（2026-10-26）

底栏贴底拉平、所有顶部贴顶、字体统一成 tab 同款，内容呈现空间更大。
6 个 TAB 与全部功能不动。

## 做了什么

- 底栏贴底拉平：去掉悬浮药丸的左右 16dp 与底部 12dp 边距、
  32dp 圆角与阴影，改通栏贴底、直角、高 60dp，只留顶部一道描边；
  图标 22dp、文字 10sp、选中色与指示线都不动。
- 所有顶部贴顶：主 Scaffold 与 10 个子页 Scaffold 的内容内边距
  只保留底部与水平方向，顶部归零；书架、音乐、直播、详情、
  书源、看图页多余的状态栏内边距一并去掉；首页网格顶边距归零，
  设置页首项上方的 12dp 间隔去掉。顶栏贴到内容顶，不再双倍留白。
- 字体统一：日志、文件预览、插件服务输出、书源页里的等宽字体
  全部改成默认无衬线，与底栏 tab 字体同款；全仓不再有自定义字体。

## 核对（没动功能）

- 6 个 TAB 不动，32 个路由不动；换源、换一换、继续观看、
  布局切换、分类筛选、迷你播放条全在。
- 播放器全屏逻辑不动：全屏时窗口层 edge-to-edge 与状态栏内边距
  保留原样；阅读器字体选择是你自己选的个人设置，跟纸色一样不动。
- 底栏仍由 Scaffold 占位，内容不会被底栏盖住；顶部贴顶后内容
  顶到状态栏下方，不压系统时间电量。

## 技术点

- Scaffold 内容内边距改 safeDrawing.only(底部＋水平)，顶部归零；
  各页多余的 statusBarsPadding 调用与无用 import 一并清掉，
  播放器全屏那处保留。
- 底栏 Surface 改通栏直角 60dp，内侧纵向边距 8dp 改 6dp。
- 双自查全绿。
