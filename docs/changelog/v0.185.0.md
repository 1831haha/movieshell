# v0.185.0

## 新增：轻量自保护壳（v0.185.0 后补，用户选“先做轻量壳”）

- 新 `AppGuard`（单一入口，`MainActivity.onCreate` 最先跑）：可调试包、调试器已连接 → 弹提示并退出；root、模拟器 → 只弹一次警告、不拦截、不误伤正常用户。
- 说清做不到的：签名验签不做——云构建每轮现场生成新 keystore、签名每版都变，写死某版签名下版自己先被挡；真验签要先换固定签名密钥（另起一版，不混进 185）。dex 加密也不做——商业加固平台才有，且可能破坏 Chaquopy / DexClassLoader 插件动态加载，未经真机验不引入。R8 混淆仍是原有那套，只抬高阅读门槛，不承诺防反编译到底。
- 待真机验：正常真机（非 root、非模拟器）启动不受影响；调试器连着启动时能退出；root/模拟器上只警告、能继续用。

## 新增

- 一键配置插件（新插件类型 `setup`）：插件市场装“一键配置：建好目录和说明”后，安装即在文件管理器建好全部目录并写入说明文档，装完 toast 会报建了几个目录、写了几份说明、跳过几份已有文件。
- 建的目录（单一入口 `StoragePaths.setupDirs()`，以后改清单只改这里）：`js/`、`py/`、`py/book/`、`php/`、`php/t4_demo/`、`php/t4_demo/lib/`、`web/`、`jar/`、`live/`、`plugins/`、`service/`、`backup/`、`log/`、`crash/`、`Download/`、`Screenshots/`，共 16 个；根目录和每个目录各一份说明文档，写清放什么文件、什么格式、在 App 里哪里管。
- 插件详情页：已安装的 setup 插件多一个“重新一键配置”按钮，删了某个目录或说明文件时点一下补齐缺的，不用重装。

## 不覆盖、不删的红线

- 说明文档已有就不覆盖，用户自己改过的说明、自己放的规则文件一律不动。
- 卸载 setup 插件只删插件自己的 `plugins/<id>/docs/` 副本，不删已建好的目录和已写入的说明，更不碰各目录里的规则文件。
- 说明文档不在安装包里，只在插件包里（`setup-dirs-1.0.0.zip` 的 `docs/`），安装包不因此变大；旧版 App 不认 `setup` 类型，安装按钮会置灰，需先升到 0.185.0。

## 已知限制与待真机验

- 未授予“所有文件访问权限”时，目录回退到 App 私有目录下的 `xiaying/`，文件管理器里看不到属正常，App 照常用；授予权限后重配一次即可落到公开目录。
- 插件市场条目 `setup-dirs` 1.0.0、`minApp` 0.185.0，需真机验：市场装插件后文件管理器里 16 个目录齐全、根目录和各目录说明可读、已有文件重装不被覆盖、卸载后目录和规则还在。
