# v0.242.0（2026-10-26）

阅读界面对标图 2：点一下正文出全套 chrome，再点收回纯文字。

## 做了什么

- 沉浸页脚（对标图 1 底部）：沉浸时正文底下只留一行小字——
  章节名 + 页码/全书进度（翻页模式是“当前页/总页 + 全书%”，
  滚动模式是“本章 %”）；点一下正文就出图 2 那套 chrome。
- 顶栏加刷新：换源、书签、章内搜索之外补一个刷新钮，重读
  本章（清缓存再重拉，页码/滚动位置不动）；本地 TXT 书没有
  可拉的链接，不摆这个钮。
- 悬浮圆钮（对标图 2 左侧竖排白圆钮）：只在 chrome 展开且无
  面板时出现，贴左下、在底栏之上——章内搜索、刷新、夜间；
  夜间钮切走时记住当前背景，再点恢复（跟随系统档也照此恢复）。
- 底栏第二排改成 目录 / 界面 / 设置（对标图 2，减去朗读）：
  界面用 Aa 字样，开显示面板；设置开阅读+管理面板。
- 设置面板拆成两个：界面面板只放显示组（字号/字体/行距/
  背景，带正文预览），设置面板只放阅读组（翻页/音量键/亮度）
  + 管理组（净化规则）；两个面板各自贴底、最高占屏高 45%、
  无遮罩，改动实时映在上面的正文里。

## 没做的两处（先说明）

- 朗读：按用户 2026-10-17 的定不做，底栏不占这个位。
- 下载：整本离线缓存是新功能，不在这版界面改动里搭；
  图 2 顶栏的下载钮与 ⋮ 更多暂不照搬（无实质内容可放，
  不摆空菜单）。

## 核对（没动功能）

- 换章落点、进度保存、书架派生、目录、书签、净化规则的
  逻辑一个没动；241 的落点认领与底部面板机制原样保留，
  只是面板由一个拆成两个。
- 刷新只清本章正文缓存再重拉，失败时走原有的“正文拉取
  失败，点击重试”可见态，不静默空白。
