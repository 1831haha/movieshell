# v0.159.0

## 改动
- 详情卡收紧（演员简介填右上角空白）：标题全宽在上，下面一行左边是集数和线路胶囊，右边是演员和简介——集数、线路右边那块空地由演员简介填上，右列不再上下叠高。演员名可点跳搜索、简介 12sp 点开全文的逻辑不变；收藏、分享、追剧仍在海报下方小图标行，不动。
- 直播选台不再必定回源1：按台名记住上次选的源（右列源1/源2、自动切源都会记），中列每台只显示一条——显示的是该台上次选的源，没选过才取第一条；中列高亮按台名判。点右列源2后，再点中列同台就还是源2，不会跳回源1；中列往下滚也不再重复出现同名台。

## 说明与已知限制
- 本版修的是“选台跳回源1”，不是直接证明源2能播：源2本身在手机 Media3 下出不出画面，仍需在 159 上单独验——点右列源2后别再点中列，单独等 20 秒看画面。
- 直播黑屏挂起不报错时，158 的自动切同名源仍切不动（它只在播放器报最终失败时触发），本版未改这一层；若源2在 159 上也黑，再查该源在手机端的实际表现，不只看服务器通不通。
- 本版包含 158 的直播页内换源、失败自动切同名源、节目单全局兜底（兜底仍需用户在直播订阅管理里自己填地址，不填不会凭空出节目单）。
