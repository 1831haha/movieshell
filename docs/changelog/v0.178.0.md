# v0.178.0

书架页按用户 2026-10-23 15:11 的截图意见重做，只动书架，音乐页不动。

## 去掉的东西

- 阅读数据条整块去掉：今日阅读 / 本周章节 / 连续打卡那张卡片、
  配套的 StatsBar 组件和统计读取都不留了（阅读页的统计记录本身没动，
  只是书架不再展示）。
- 顶部小按钮的检查更新和批量管理去掉。

## 顶部只留三个

- 添加本地书籍、找书、书源管理，顺序和原来相对位置一致。
- 添加原来点开下拉只有“添加本地书籍”一项，多余一步，
  现在点图标直接进 TXT 导入，逻辑不变。

## 检查更新改下拉刷新

- 书架列表/网格下拉，跑的就是原来检查更新那套（获取最新章节），
  提示文案不变：都追上了 / N 本有更新。
- 刷新进行时下拉指示转圈，防重入沿用原来的 checking 状态。

## 长按小说出全选 / 分组 / 收藏

- 长按任意一本（列表和网格都一样），操作表最上面三行就是
  全选、分组、收藏，下面原来的继续阅读 / 详情 / 换源 / 删除都在。
- 全选：直接进多选模式并选中当前分组下全部书，
  顶部“已选 N 本”栏的删除 / 分组 / 取消照常能用。
- 分组：沿用原来的移入分组，不新造入口。
- 收藏：不另建表，就是自定义分组里一个叫“收藏”的分组，
  没有就现建，已在里面就取消收藏；分组横滑里能看到“收藏”分组，
  删书时随分组映射一起清。已收藏的书长按显示“取消收藏”。
- 多选模式下长按仍是点选/取消点选，不弹操作表。
