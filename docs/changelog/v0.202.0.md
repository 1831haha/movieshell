# v0.202.0（2026-10-24）：嗅探/爬虫补齐——小说通用正文兜底 + 视频转义地址还原

GitHub 巡查结论：视频嗅探开源圈最强打法（WebView 拦截 + 后缀判定 + 排序）与侠影
SniffEngine 同构，侠影还多 SW 拦截、.ts 反推播放列表、blob 深挖、Content-Type
探针这几层，无可直接抄的更强轮子；本版只补两个真缺口。

## 新能力

- **小说通用正文兜底**：新增依赖 net.dankito.readability4j:readability4j:1.0.8
  （Mozilla Readability 的 Kotlin 移植，Apache 2.0；Jsoup 已有）。
  NovelSourceEngine.content() 两条链（纯 CSS 与 JS）最后一步：规则提空时用
  Readability4J 从整页提正文；无 content 规则的源也由此可读（之前直接空白页）。
  兜底失败返回空，不抛；兜底文本不再过 ruleContentReplace（那是按规则输出写的）。
- **视频转义地址还原**：WebSniffScreen blob 深挖扫到的候选 URL，入选前先还原
  JSON 转义（`\/` → `/`、`\u0026` → `&`、`\u002f` → `/`），否则带反斜杠的
  地址进播放器是坏链。
