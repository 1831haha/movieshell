## 改法

- 书架内直接搜：书架顶栏的搜索钮、空书架的找书按钮不再跳单独找书页，点开即在书架内嵌找书（复用找书页本身，自动聚焦弹出键盘），搜完点“取消”回书架。书架页参数里那个跳页回调已删。
- 书源卡片统一：PY 书源卡片标题不再显示 BaseSpider 这类蜘蛛类名，直接显示文件名（第一版主）；JSON 卡片与 PY 卡片同为“标题 + 一行副信息 + 开关 + 删除”的结构（PY 多一个连通性测试钮，那是功能差异不是样式差异）。抠类名的 extractTitle 已删。
- 阅读点按恢复菜单：撤掉 194 的点击分区翻页（上 1/3、下 1/3、中部弹设置）。点按正文恢复成只切换顶底栏——出来就是上一章 / 目录 / 设置 / 下一章那一栏，不再翻页。设置仍走底栏“设置”钮。
- 阅读设置恢复悬浮弹窗：撤掉 194 的底部面板，改回居中悬浮弹窗（跟随主题的底色不动）；内容按组分层：预览置顶，下面分“显示”（字号/字体/行距/背景）、“阅读”（翻页/音量键/亮度）、“章节”（上一章/目录/下一章）、“管理”（净化规则），组与组之间有分隔线。五档字体、预览、章节快捷都保留。
- 滑动跨章（新补的，194 漏了这一块）：上下滚动模式下，手指滑到章末继续上滑进下一章、滑到章首继续下滑回上一章；用手指剩余滑动量触发，一次手势只跳一章，短章也不会一次滑过连跳多章。音量键跨章仍是 194 那套（章末按减进下一章、章首按加回上一章末页）。
