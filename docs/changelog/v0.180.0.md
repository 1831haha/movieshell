# v0.180.0

书架页顶行纠偏 + 音乐页重设计。

## 书架：全部真提顶行

- 179 把“最前面”理解成分组横滑第一项，理解错了，本版纠正：
  顶行左侧就是“全部”胶囊，右侧是搜索和三点菜单，
  不再是顶行只有搜索/三点、全部在下面一排。
- 最近阅读那一行同步提上来：放在顶行下面、自定义分组上面，
  顺序是顶行（全部/搜索/三点）→ 最近阅读（排序/N 本/视图切换）
  → 自定义分组横滑 → 书单内容。
- 自定义分组横滑里不再重复“全部”，只剩自定义分组 + “+ 分组”。
- 点顶行“全部”回全部，点自定义分组切分组，逻辑不变；
  178 的下拉刷新、长按全选 / 分组 / 收藏都没动。

## 音乐页重设计

- 平台分类不再写死：网易 / QQ / 酷狗 / 酷我 / 咪咕这排
  是跟随当前 LX 音源（墨澜类聚合脚本）来的——音源 inited
  自报几个平台，平台行就列几个，横滑排布，再多也不会被挤扁。
  音源没加载出来时先按已知可搜索平台兜底显示，加载成功后刷新。
  短标签由 MusicApi.platformShortLabel 从全名派生，UI 里不再另写
  一张五家对照表；播放页同曲换平台也改走数据层单点口径。
- 音源以后报出新平台时：平台行自动多一个选项；但搜索接口
  还没接上的平台会置灰并有小字说明“搜索接口还没接上”，
  不会假装能搜。真正点亮新平台只要数据层加 code 并接上
  PlatformMusicApi 的搜索接口，UI 不用改。
- 已选平台即使不在新音源里也保留一行，避免已选状态凭空消失；
  已选平台的记忆也不再被“认不出就打回网易”——认不出的 code
  原样保留，等接口接上就能用。
- 音源条重做：以前右对齐一排、两个功能只有无文字图标，
  看着悬空还不知道当前是哪个源；改成一张卡，左边点开就是
  切换音源，当前源名（无首选时显示“自动”）写在卡上，
  右边歌单导入 / 源管理全带文字。
- 榜单区重做：以前 2x2 小卡只占上半截，下半页大片空白；
  改竖排满宽列表 + 底部“榜单怎么用”说明卡，点榜单名仍是
  导入整榜，切平台后搜索和榜单都跟着换。标题由“推荐歌单”
  改回“推荐榜单”。
