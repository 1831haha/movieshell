# v0.182.0

换源弹窗按截图改成 2 列大卡，并给三种排列任选。

## 改了什么

- 默认排列改成截图式 2 列大卡：左边源名（可换两行），
  右边一个类型小标签，第二行写来源和是不是当前源，
  当前源有炫彩描边，一眼认得出来。
- 标题改成“切换站源”，右边加了关闭，搜索框提示改成
  截图那句“输入站源名称关键词进行检索…”。
- 搜索框右边加了一个小宫格切换按钮，点一下换一种排列，
  一共三种，都用同一批现在的源，不改源本身：
  大卡（截图式，默认）/ 图标（原来 5 列小图标）/ 列表
  （图标 + 名 + 类型一行，名字长、源多时好翻）。
- 类型筛选 chips、搜索过滤、刷新、打开定位到当前源、
  点选切换逻辑都没动；不支持的源还是半透明点开提示原因。

## 没编假数据，特意说明

- 截图里“4K超清、无广直连、多线并发、响应速度：秒播”
  那些标签，咱们源数据里没有，App 也测不出来，不能凭空编
  一个贴上去。所以大卡右边小标签用的是真实有的类型
  （CMS / drpy / PY / PHP / spider），第二行用的是真实有的
  来源（本地规则 / 订阅站源）和当前源标记。
- 如果以后订阅那边给源加了标签字段，再把标签原样显示
  到卡片上，不用改排法。

## 待真机验

- 首页换源弹窗打开默认就是 2 列大卡，点搜索框右边
  的小按钮能依次切到图标、列表，再切回大卡。
- 长源名在大卡里换两行不溢出，当前源描边和“当前源”
  字样对得上，点卡还是切换源。
- 列表模式下名字长的一行能截断，图标、类型、来源都对。
- 本地无编译器，语义仍以云构建为准；双自查脚本已绿。
