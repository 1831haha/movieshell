# v0.244.0（2026-10-26）

整本连续阅读：滚动模式整本书一个连续流，翻页模式整本
统一分页；章界不再是断点，标题就是流里的普通文本块。

## 滚动模式：一个连续流

- 整本书放进一个列表里滑：滑过章界不跳章、不回顶，
  上一章正文后面直接就是下一章标题、再接下一章正文。
- 顶栏章节名、底栏滑杆、进度保存都跟视口走：滑到哪章，
  显示的就是哪章，滑杆就是本章进度。
- 章内搜索、目录、书签、滑杆、上下章按钮全部走同一套
  定位：目标章正文没到先拉取，到了再精确定位到那一行，
  滚动停稳才落点（241/243 的守门原则保留）。

## 翻页模式：整本统一分页

- 不再按章切页：一页里可以同时装上一章结尾、下一章
  标题、下一章开头，页边界只由实际排版容量决定。
- 标题不特殊：不强制换页、不独占一页、不置顶、不做
  标题避让，该断就断，和正文一样翻。
- 页码改成全局页：长书先按当前页附近增量排，总页数
  没算完时显示“计算中”，不硬编一个假总数。
- 旧的重叠行逻辑删了：统一分页下每页边界本来就是
  精确的，再把上一页末行贴到下一页首会重复。

## 定位语义（和 GPT 三轮核对后定死）

- 目录跳转：到目标章标题那一页。
- 上一章按钮：回上一章末页（233 定论；GPT 第三轮曾
  定成标题页，已纠正）。
- 书签、滑杆松手、章内搜索：按章节 + 字符偏移落点；
  偏移 0 就是章首（标题可见）。
- 老进度不用迁：进度文件还是章节 + 字符偏移，靠映射
  换算全局页；字号、行距、字体、屏尺寸一变，分页整体
  重建，落点按原章节 + 偏移重新定位。

## 音量键与越界

- 滚动模式：到头按上一页回上一章末页，到底按下一页
  进下一章章首；中间按页滚（屏高减一行）。
- 翻页模式：第 0 页就是书首、排完就是书末，到头到底
  停住，不再跨章跳。
- 手指越界跳章的两套连接（滚动 boundaryScroll、翻页
  pagerBoundaryScroll）删了：连续流和全局页本来就没有
  章界可越，留着只会捣乱。

## 不动的东西

- 书架、书源、播放器一个没动；朗读按既定不做；翻页
  动画（覆盖/滑动/仿真）这版不重写，仿真旋转只保留为
  视觉效果，不影响页内容与全局索引。
- 旧按章分页引擎（NovelPaginator）文件先留着，阅读页
  不再用它；阅读 3.0（legado）那边核实过：它本身也是
  按章排版、章末切章，不是整本统一分页，所以全局页是
  按咱们的架构自写的，只借鉴了实测排版、页内字符映射、
  邻接章预加载、动画与内容分离这几条。
