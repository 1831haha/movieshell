# v0.149.0

> 状态：版本档案 ｜ 日期：2026-10-22 ｜ tag v0.149.0

## 新功能

- 嗅探更准了，带 .js 后缀的假 m3u8 不再被当成直链。
- 主 frame 的 /m3u8/ 路径壳页不再被误判为直链。
- 候选列表按 m3u8、mp4/mpd、其他的顺序排，好链排前面。
- 播放失败时，嗅探直链带 Referer 的情况下多一个“清除 Referer 后重试”。
- 候选面板多了拦截和 iframe 诊断行，能看出候选是从哪来的。

## 修复

- 点选候选前会先校验播放请求头，文本、脚本、JSON、CSS、图片类假地址会被拦下，含糊的放行。
- 20 秒超时不再作废已到手的候选，候选非空可继续点选，零候选时自动把已拦截队列再探一轮。
- 懒播放只点已知播放器的大播放键，每页一次，且只在候选为空时触发。
- CF 验证页只提示一次，不自动绕过。

## 已知限制

- 本版 6 个嗅探案例的改动尚未真机逐项验证。
- player_aaaa 这类加密地址只记日志、不解密，播不了的仍播不了。
- CF 全自动绕过不做，需要在真窗口里手动过验证。
- FongMi/TV 全局规则原文和 DSINFO 独立诊断页这次没做，现有自定义正则和面板诊断行是等价替代。
