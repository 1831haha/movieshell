# v0.234.0（2026-10-26）

新 UI 第一版：首页与书架 Hero 大卡领头，全页面入口逐一核对无丢失。

## 做了什么

- 首页 Hero：海报网格布局下，当前列表第一条放大成 16:9 宽幅大卡
  领头，封面＋标题＋年份分类＋备注，点进详情和原来一样；
  网格里跳过这一条，不重复显示。列表、纯文字两种布局不动。
- 书架继续读 Hero：最近读过的那本放大成“继续读”宽幅卡领头，
  副标题是作者、在读到第几章、有没有更新，点进直接续读；
  网格和列表两种视图都有；多选书的时候它不出现，列表完整，
  多选语义不受影响。
- 新共享组件：HeroCard（宽幅大卡）、ListRow（缩略图＋标题／
  副标题＋尾巴槽），都沿用现有 token（毛玻璃底＋微光描边＋
  PosterCard 同款占位回落）。

## 核对（没硬换、没丢功能）

- 设置：SettingsGroup 分组（播放与解析／插件与同步／存储与
  帮助）早已是分组卡片，本版不动。
- 详情：AppCard／SectionTitle／EmptyState 早已在共享组件
  体系内，本版不动。
- 追剧：PosterCard 网格＋EmptyState，本版不动。
- 历史：手写 HistoryRow 含进度与操作，硬套 ListRow 会丢功能，
  不做。
- 搜索：私有 SectionHeader 是图标＋标题，与共享 SectionTitle
  金色标题不同款，不做。
- 直播／阅读／音乐：已在共享组件体系内；播放页是专用播放面，
  不套卡片。
- 导航：底栏 5 个 TAB 不动（首页／直播／书架／音乐／设置）；
  31 个路由逐一对过入口，全部可达；两个 Hero 的点进逻辑与
  原卡片完全一致（首页 goDetail、书架 openNovel），Hero 出现时
  列表里跳过这一条、不重复。

## 技术点

- 新增 ui/components/HeroCard.kt、ListRow.kt；双自查全绿。
- HomeScreen：海报网格布局才有 Hero（showHero 排除
  COMPACT_LIST／TEXT_ONLY），items 走 filtered.drop(1)。
- BookshelfScreen：continueBook 取当前可见书里最近读过的一本
  （progressMap.updatedAt 最大），多选模式下为 null；副标题
  共用 continueHeroSubtitle 一段，网格／列表两处同调；
  continueHeroSubtitle 与 openNovel 的声明行都在使用行之前。
