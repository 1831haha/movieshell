# v0.239.0（2026-10-26）

音乐两个入口改胶囊钮、阅读进度条改全本进度、书籍详情弹窗瘦身、
书架继续读大卡撤掉。功能入口一个不少。

## 做了什么

- 音乐入口好看了：顶栏右边的“歌单导入”“源管理”原来是裸蓝色
  文字链，看着像没做完；现改成跟下方页签同款的浅灰底胶囊钮，
  在线页签下两个都在，非在线时只留右对齐的“源管理”。
- 阅读进度条改全本进度：原来滑块只取章序号，章内滚动时滑块
  纹丝不动，看着像“这一章的进度”；现把章内进度折进章序号
  （滚动模式取滚动比例，翻页模式取当前页比例），滑块位置就是
  全本位置，拖动松手仍按章跳，跳转语义不动；顶栏的百分比不动。
- 书籍详情弹窗瘦身：长按书籍出来的弹窗原来接近满屏；封面
  110x148 改 84x112，行距与分隔间距同步收紧，动作小钮同步
  缩一圈；作者、来源、最新、分组、追更、目录、收藏、净化规则
  与底部删除/阅读两钮全在。
- 书架继续读大卡撤掉：刚读过的书不再放大成宽幅卡领头，
  所有书一律按普通卡/行排，刚读过的那本回到它在列表里的
  正常位置；网格与列表两种布局都撤。

## 核对（没动功能）

- 歌单导入弹窗、源管理页入口与行为不动；换源、目录跳转、
  分组、收藏、删除、净化规则全在。
- 底栏抽成独立组件：章内滚动每像素都变滚动值，只重组底栏
  这一小块，不触发整页重组。
- 双自查全绿。
