# v0.223.0（2026-10-25）

书源管理页卡片化、找书框与加载圈重设计，999 搜书加诊断日志。

## 书源管理页

- 每个书源单独卡片（毛玻璃卡 + 微光描边，AppCard）：第一行书名 + 开关
  （开关恒贴右缘），第二行地址 + 操作钮（操作列恒贴右缘），各卡片开关
  与操作列纵向对齐；卡片间距 8dp，分隔线去掉。点卡/长按行为不变
  （JSON 源点卡进字段编辑、长按进文本编辑；PY 源点卡打开、长按进文本编辑）。
- 头部压缩：说明只留一行“开关控制搜索时是否使用该源”；发现聚合/
  净化规则/恢复默认由三个通栏大钮并成一行小钮，省约 110dp。

## 找书搜索框

- 独立找书页与书架标题行两只框同一样式：整条一体，左搜索图标 +
  无框输入 + 右清除/搜索，不再是胶囊描边框 + 外挂搜索钮；填充底 +
  聚焦青色描边；键盘搜索键直达搜索。

## 搜索加载圈

- 细环 32dp、无中央点，主副两行文案（“正在搜索…”+“N 个书源”）；
  颜色语义不动，黄仍是加载中。StatusRing 新增 showDot/strokeWidth
  参数，其余调用点默认行为不变。

## 999 搜书诊断日志（只记长度与条数，不记正文）

- 未抓到页记一行；校验（1234 握手）前后长度与解析条数记一行。
  搜不到时凭这一行即可分清是请求问题、握手改写了页，还是解析出空。
