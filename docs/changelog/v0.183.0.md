# v0.183.0

源小卡片高清化：图标不再拿模糊小图硬放大。

## 模糊的根因

- 以前站源图标第四级直接取站点根目录的 favicon.ico，
  那东西通常只有 16x16 / 32x32，放大到 44dp 卡片上必然糊；
  再加上原来用 Crop 裁切，矩形图还会被放大裁掉边缘糊一圈。

## 改法

- 高清候选链（只走站点自己，不走第三方图标服务，不会
  被通用占位图盖掉首字）：先试本站的 apple-touch-icon.png
  （180x180），没有再试 favicon-192.png，失败逐级降，
  最后一张才是 favicon.ico，实在什么都没有才回首字色块。
  顺序只留 3 张，免得 130 个源的弹窗刷一堆 404 请求。
- 渲染改成 Fit 不裁切 + High 高质量缩放：180/192 的高清图
  缩到 44dp 时边缘更利落，矩形图不再被裁。
- 图标方块加了一圈细描边，2 列大卡顶上也加了 40dp 的
  高清图标（图标 + 类型标签一排，名字放下面），不再是
  纯文字卡；5 列小图标和列表行共用同一套高清图标逻辑。
- ext 本身就是图片 URL、内置图标表的那批源不受影响，
  还是走原来那张图。

## 待真机验

- 换源弹窗里原来糊的图标，现在是不是清楚了；没有高清图
  的站还是首字色块，不会变成通用地球占位图。
- 2 列大卡顶上有图标，名字、类型、来源都对得上；
  5 列图标卡和列表行的图标也一样清楚。
- 本地无编译器，语义仍以云构建为准；双自查脚本已绿。
