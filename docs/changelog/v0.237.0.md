# v0.237.0（2026-10-26）

浅色高密度改版：跟参考图走浅色，布局主题全换，内容一屏看更多。
6 个 TAB 与全部功能不动。

## 做了什么

- 主题改浅色：纯白底、近黑字、参考蓝主色；没显式选过主题模式的
  老用户一次性切到浅色（设置、外观里仍可切回跟随系统／深色），
  新装默认就是浅色；不管之前选过什么主题色，装上就是参考图的样子。
- 首页 Hero 大卡撤掉，网格直接三列密排；边距从 16dp 收到 12dp、
  间距从 12dp 收到 8dp；首页流动光斑与自定义底图在浅色下不画，
  不再占视觉地方。
- 海报卡按参考图重做：卡片本身无底无边，只有海报图带小圆角；
  角标挪到右上角黑底白字胶囊；标题 plain 黑字一行省略，不跑马灯。
- 筛选 chip 按参考图：选中浅蓝底＋参考蓝字，未选中浅灰底＋灰字，
  无描边无阴影，高度收紧；分区标题在浅色下用近黑。
- 底栏在浅色下改白底、浅灰描边、参考蓝选中、阴影收淡；
  形状与 6 项均分不动。

## 核对（没动功能）

- 6 个 TAB 不动，32 个路由不动，全部功能入口不动；换一换、
  继续观看、换源胶囊、布局切换、分类筛选全在。
- 深色主题保持原样：毛玻璃、光斑、青色主色、主题色与炫彩预设
  在深色下仍生效；浅色下主题色、炫彩预设、自定义底图暂时不生效，
  切回深色即恢复——这是浅色固定参考样式的有意取舍，不是 bug。
- 刻意没动的语义色：榜单四色、音质分档、阅读纸色、状态环、
  收藏粉心、成功／失败／提醒色。

## 技术点

- 浅色色板固定（白底、近黑字、参考蓝），不跟主题色参数走；
  浅色下品牌渐变固定参考蓝单色系。
- 主题模式默认值改浅色；老用户跟随系统模式一次性迁移到浅色
  （显式深色不动），迁移标志记 movieshell_migrations。
- 首页 Hero 撤掉后网格不再 drop(1)，HeroCard 组件仍留给书架
  继续读用；双自查全绿。
