> 状态：版本档案 ｜ 日期：2026-10-22 ｜ tag v0.156.0

## 修复

- 字幕设置面板一页完整、不再拖动：155 那版只是把内容区封顶、按钮不被裁，但面板内容本身（地址+搜索+大小+颜色+描边+位置+时间偏移，竖着堆要约 470dp）还是比内容区上限高，时间偏移那行被截一半，得在面板里拖一下才能看全——用户截图里就是这样。
- 改法：每组改成标签+控件同一行（大小是“大小+滑杆+16sp”一行，颜色是“颜色+色点”一行，描边/位置是标签+小胶囊一行，时间偏移是“时间偏移+滑杆+秒数”一行），不再标签一行、控件一行堆高；卡片内容区对字幕面板关掉滚动，一页就是一页。
- 横屏（宽>高）再左右分两列：左列地址/在线搜索/大小/颜色，右列描边/位置/时间偏移，高度压进横屏内容区上限，不靠拖动也不被裁。
- 其他共用该卡片的面板（定时关闭等）仍可滚动，不受影响；字幕地址、在线搜索、大小、颜色、描边、位置、时间偏移的功能和保存逻辑都不动。
