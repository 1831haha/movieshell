# v0.171.0

本版包含此前未推送的 v0.170.0 那批（备份恢复链校验与回滚、JSON store
原子写盘、首页换源胶囊灰圈与外圈），170 不单独发版，171 一次性推送。

## 插件安装回滚（PluginMarket / ServicePluginManager / JarSpiderStore）
- 市场插件 server 与 runtime 分支：先解到同目录暂存目录，全部解完才整体
  替换旧目录；解压中途失败时旧目录原样保留、注册表不更新，不再出现
  "旧版已删、新版残缺、注册表仍显示旧版"的不一致态。
- 服务插件 install：先解暂存目录，在暂存目录上验可执行文件，通过后才替换
  旧目录并写注册表；验失败时旧目录与注册表都不动，且此前已停的旧进程
  会尽力拉回（此前先删旧目录再解压，验失败即丢旧版）。
- spider jar：订阅 spider 字段的 `;md5` 段不再被 resolveJarUrl 剥掉丢弃，
  随解析地址一起保留；下载先写临时文件、md5（有的话）通过后才改名进缓存，
  中途断网只留临时文件；已有缓存带 md5 时必验，不符的当残包删掉重下。

## 订阅安全（SiteRepository / SubSiteStore / SourceProbe）
- 非法订阅不再清空现有站源：先载入到临时结构，顶层无 sites 数组、或
  sites 数组过滤后一条有效站源都没有时，保留旧列表并记日志返回旧列表；
  替换只在校验通过后发生。
- 站源去重：同一订阅内同 key 只留首条；聚合层按 key 与归一化 URL 去重
  （URL 仅差尾斜杠、域名大小写、默认端口时算同一站源，首条胜出）。
- 探活覆盖订阅展开的全部 sub: 子站与 js/subs、py/subs 下的规则文件：
  drpy/py 子站跑规则首页、CMS/type4 走 HTTP、spider 验 jar 落地、
  unsupported 直接报展开时记的原因；已由子站任务覆盖的 subs 文件不再重复探。

## 下载（DownloadStore / DownloadQueueWorker / DownloadManager）
- m3u8 半截分片不再记 DONE：分片改走临时文件写完改名，正式文件只会是
  完整的；恢复下载时把边界分片（最后一个已计入的分片）重下一遍，171 之前
  留下的半截分片在续下时也被修复（代价是多下一个分片）。
- 直链成品：记录过总大小时必对长度，对不上删掉重下，不再把半截成品当 DONE。
- 清已完成：删记录的同时删文件，Download 目录下的视频与分片不再成孤儿。
- 删除任务：等 Worker 真停（在途标记消失）再删目录，不再只看状态位——
  此前 pause 后状态立刻变 PAUSED，旧等待条件马上退出，Worker 还在写盘时
  目录就被删，写盘随后又把孤儿目录建回来；分片在 64KB 块边界查暂停，
  暂停后最多一个块即停；30 秒仍未停则继续删并记日志。
- 自动清理改按完成时间算：DownloadTask 新增 completedAt（完成时写），
  8 天前入队、昨天才下完的剧不再到期即被删；老记录无完成时间时回退到入队时间。

## UI 静默失败（详情 / 直播 / 历史 / 设置）
- 追剧失败给可见提示：追剧与取消追剧写盘失败时弹"追剧失败，请重试" /
  "取消追剧失败，请重试"，不再点了没反应。
- 空地址点集不再静默记已看：先解析出地址，空白时弹"该集暂无播放地址"
  并返回，不记已看、不写播放会话、不进只剩封面的空白播放区。
- 历史空 URL 不再进黑屏播放器：历史页点击时先提示"该条历史没有播放地址"，
  navigateToPlayer 本身也对空地址直接不跳转。
- 详情 0 集有空提示：选集区无剧集时显示"暂无可播放剧集"，不再只剩标题加空白。
- 详情 reloadDetail 加世代号与旧任务取消：刷新、重试、切集并发的请求，
  旧请求迟到时不再覆盖新结果、也不再把加载态提前置 false。
- 直播分组选中态切 tab 不丢：LiveSelection 补存分组与源行选中态，切 tab
  回来恢复到原分组与原源，不再回首组与"全部"。
- 设置页统计失败不再显示 0：任一统计失败时资料卡整行显示"—"与"统计失败"，
  不再用 0 冒充"真没有"（失败原因仍记应用日志）。

## 已知限制（本批未动，留后续版本）
- 171 仍未覆盖的审计项：V8/PY/PHP 引擎的超时与并发问题、嗅探请求头丢失、
  换内核不断旧引擎与断点取自新引擎、字幕跨集不重置、订阅刷新失败重试、
  插件市场 MD5 信任锚（仍是自证式 MD5，无签名）、源/规则文件删除残留、
  详情进程重建丢集数、应用内更新日志仍停在 v0.64.0、设置页"关于侠影"占位
  点击无行为、死代码与未使用 import 清理。以上均未动，不得理解为已修完。
- 插件 source/env/player/subtitle 分支写的是共享规则目录而非单插件目录，
  无法整体暂存替换，本版仍直接写盘（失败时注册表不更新，但已落盘的部分
  规则文件可能残留）；server/runtime/service 三路已做暂存替换。
- 无 md5 的 jar 仍只能验长度：171 之前留下的无 md5 半截 jar 无法凭文件本身
  区分，仍以长度大于 0 当有效；带 md5 的 jar 已可凭校验发现残包。
- 下载删除等待 30 秒超时后仍继续删：极端情况下 Worker 在删目录后的一小段
  时间内仍可能写一个 64KB 块，属已知残留窗口，下次删除任务时可清。
- 本版未做写盘锁（RMW 并发丢更新）与备份覆盖扩展（170 已知限制仍有效）。
