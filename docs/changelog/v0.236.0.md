# v0.236.0（2026-10-26）

全量风格统一：青色系取代紫加金，6 个 TAB 与全部功能不动。

## 做了什么

- 主色从紫改成青（与底栏选中色同款），开关、按钮、进度、
  选中态这些跟主色走的地方全跟着变。
- 品牌渐变从彩虹（青／靛／品红／金）改成青到蓝；详情页
  操作标那道渐变改走品牌渐变，不再是四色。
- 分区标题从金改成青，浅色主题下用深青，保证对比度；
  弹窗标题、Toast 描边、书架空态插画图标里的旧金一并清掉。
- 首页顶部流动光斑从紫、粉改成青、青绿，流动本身没动。
- 找书详情页的类型标签和阅读按钮、播放页的引擎标和进度条，
  原来是写死的材料蓝，全部改成跟主题主色走。
- 底色、毛玻璃、微光描边、圆角本来就是 DaoBox 方向，没动。

## 核对（没动功能、没动布局）

- 6 个 TAB 不动，32 个路由不动，全部功能入口不动；
  本轮 18 个文件只动颜色，没动任何布局、路由、逻辑。
- 刻意没动的语义色：榜单四色是每榜一个数据色；音质分档
  是无损青、高清蓝、其余灰；阅读纸色米黄、护眼绿、夜间黑
  是用户自选的纸；状态环绿／黄／红／灰、收藏粉心、
  成功／失败／提醒色都是语义色，动了反而乱。
- 设置里用户自选的主题色和炫彩预设（极光等）没动；
  如果以前在设置里手动选过主题色，那个选择会盖住新默认色，
  在设置、外观里重选青色就行。

## 技术点

- 默认主题色与品牌渐变默认值统一改青色；标题色函数
  goldTitleColor 更名为 accentTitleColor（深色青、浅色深青），
  调用处一并更名；详情操作标渐变改走品牌渐变默认值；
  找书详情与播放页的写死蓝色改走主题主色。
- 双自查全绿；旧金色值与旧名全仓清零。
