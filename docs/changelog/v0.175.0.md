## 播放失败自动换线路后，详情页显示跟上

- 现象（真机实证，2026-10-23《一英里》）：qq 线路播失败，App
  弹“已自动切换到「youku」”，实际也已经在播 youku 的地址，
  但详情页下面线路 Tab 还下划线在 qq、简介旁的源胶囊还是 qq、
  选集列表还是 qq 那 2 集，看着像没切过去。
- 根因：自动换线路只改了播放器内部的 PlaySession（所以真在播
  youku），但没走手动切线路那条通知；详情页的选中线路收不到，
  Tab、胶囊、选集列表全停在旧线路。详情页里还有个 playingLine
  只写不读，等于没同步过。
- 改法：自动换线路和手动切线路走同一条通知；详情页收到后把
  选中线路和选中集一起同步到新线路，Tab 下划线、源胶囊、选集
  列表、高亮集都跟到 youku。手动在播放器里切线路、片尾自动
  下一集也是同一条路，顺带一起修好。
