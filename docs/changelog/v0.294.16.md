# v0.294.16

修复音乐播放页「暂无歌词」（QQ / 墨澜等非网易云源）。

- 根因：`MusicApi.lyric` 只走 GD Studio，而 GD 歌词实测仅支持网易云（wy）；tx/kw/kg/mg 直接返回空表，歌词开关打开也只显示「暂无歌词」。
- tx（QQ 音乐 / 墨澜聚合出的 QQ 曲）：按 songmid 调 QQ 公开歌词接口取 LRC。
- 仍无词时：按歌名+歌手在网易云搜索同曲（`pickSameSong`），再经 GD 取词。
- 空态保留「暂无歌词」，并附一句轻量说明（拉取与跨源兜底都结束后仍空）。
- 版本 0.294.16 / versionCode 378。
