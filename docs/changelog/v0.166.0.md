# v0.166.0

- 首页首屏降级从 8 秒砍到 3 秒：推荐 3 秒没回，立即渲染缓存或空态占位，不再白看 8 秒空屏。
- 首屏等待队列 5 秒截断：推荐 / 分类两路结算最多等 5 秒，慢源不再拖住整个首屏；慢路不取消，25 秒上限内回来照样前台补填。
- 空结果不覆盖缓存：推荐返回空列表时保留已渲染内容，不再出现“20 条闪没”；分类路本来就有这层保护，这次不动。
- 崩溃扫尾：全局搜不到字面 `key = "debug"`（10-20 那次是 raw-string key 撞车，搜索历史那路已有去重）；把剩下两处可能撞车的 key 也钉死——观看历史 key 拼时间戳、嗅探测试结果先去重。

## 已知限制

- 5 秒截断只截断首屏结算：21 秒那种慢规则首页内容会晚到（3 秒先给缓存/空态，回来再补），不是 5 秒内一定出齐。
- 25 秒硬上限仍在：超过 25 秒才回的规则，首页仍按失败处理。
- 5 秒后若立即下拉刷新，可能与上一轮慢请求短暂重叠，旧请求结果会被世代检查丢弃，不会刷错界面。
