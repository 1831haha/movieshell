# v0.152.0

> 状态：版本档案 ｜ 日期：2026-10-22 ｜ tag v0.152.0

## 新功能

- RTMP 终于能在 App 内播了：嗅到 rtmp 进候选列表、点选后走 libmpv 播，未装 libmpv 插件时提示去市场安装，不改你的内核设置。
- 解析线路嗅到 rtmp 也直接返回给播放器，不再只记日志。

## 修复

- PHP 规则失败不再只显示空首页：首页会直接显示 PHP 的真实原因，比如 php 没装、退出码、缺 lib/spider 文件。
- 批量检测里 PHP 规则也不再一律显示不支持，跑不通就显示失败原因。
- libmpv 播放失败不再只有一句固定文案，失败提示和日志会带上地址、播到第几秒、是否出画面、起播后多久断，直播失败时能定位了。

## 已知限制

- RTMP 只走 libmpv，Media3 本身不吃 rtmp；没装插件时 RTMP 播不了是预期，装插件即可。
- libmpv 的 END_FILE 回调只给事件 id、不给 mpv 内部错误串，所以失败画像用的是已观测到的播到第几秒、是否出画面等信息，不是 mpv 的原始错误码。
- 通用 Node CLI 仍不做：没有可复用的 Android Node 二进制，drpy-node 的手机包是 Termux 方案，不是插件二进制；只有用户拿出具体跑不动的 Node 源时才单文件核对。
- 投屏、字幕拖拽、Anime4K 不进这版；小说语音朗读按用户要求永不做。
