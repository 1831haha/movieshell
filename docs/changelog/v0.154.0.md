## 修复

- 直播中央大三角显示错：播着还挂着大播放键。根因是 libmpv 的暂停状态只靠 mpv 属性变化回调同步，起播时 mpv 本来就不是暂停，设成不暂停不会触发回调，本地状态一直卡在“已暂停”，界面就一直以为没在播。现在起播、暂停、恢复、异常结束时本地状态同步置，不再只等回调；回调仍保留作兜底。修完应是：播着不显示大键，暂停才显示。

## 调查结论（不改播放逻辑）

- CCTV1 那条 0001_1 播不了，不是 libmpv 通病：同一时段另一台直播地址（0128_1）能正常返回播放列表，而 0001_1 那台服务器直接空回包、连不上；手机上 Media3 播同一地址也报过 HTTP 错误，湖南卫视那路能播也佐证这一点。服务器本身不通，App 里改播放逻辑救不回来，153/154 不对这条做盲改；这条线路要等订阅源那边恢复，或手动切直播右列的其他源。
