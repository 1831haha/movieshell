## 引擎与性能（M11-M15、M28-M32、M03）

- M12：共享 home 缓存加 Mutex 单例化，换规则/释放用世代号兜底，旧 eval 不写缓存；RPC 失败路径统一结算在途 Promise；awaitJs 注册取消；JsRuntime.close 加 5 秒超时。
- M13：DrpySourceManager 换规则用世代号，旧引擎结果对不上世代即丢弃，不记失败原因。
- M14：PyApi 失败结果不进共享 home 缓存；PY play 失败记规则路径与原因；Chaquopy ensureLibsPath 失败不置位；PHP 成功取到 JSON 时清 lastError，超时单独记“超时”而非退出码 -1，lib 缺失记日志。

- M28：聚合搜索普通失败也记带源名 warning，搜索页脚汇总“X 个源失败”；订阅刷新失败源优先重试，补跑任务退避 4 小时→8 小时、最多 2 次。
- M29：EPG 下载分块限量 20MB、按 URL+日期磁盘缓存一天；直播订阅并行拉取（限流 4）+频道列表落盘缓存；刷新失败的源保留旧频道并标“过期”，直播页频道行显示“过期”徽标。
- M30：同步 execute 全部改为取消即 cancel 底层 call；重试耗尽补收尾日志；调用方总超时本就小于底层 60 秒 callTimeout。
- M32：PHP 探活自己包 guarded() 8 秒硬超时，成功返回实测耗时，失败原因按任务携带、不读共享 lastError；补 isRuleEnabled 检查。
- M03：播放页切集时先清上一集手动选的字幕与弹幕列表再拉新。

## 本版未做 / 延期 / 需先验先定

- 需真机验才能定的 M08（直播 8 秒 watchdog 抢跑）、M09（AppGuard 硬拦截后自启动服务残留）、M10（子进程服务是否绑 0.0.0.0 且无鉴权）未做，只做数据与文档准备，不替设备结论。
- 需用户产品决策的未做：M22 签名信任锚（签名公钥）、L18 底部 dock 颜色是否跟主题、L21 频道/分组是否落盘、长按底部首页 tab 三选项（回顶/刷新当前源/快捷菜单）。长按底部首页 tab 仍未实施，不得写成已做。
- WebDAV 密码迁 EncryptedSharedPreferences 继续延期：全仓仍无该依赖，不凭空加未验证依赖，密码仍存普通 cloud_sync_prefs，不要宣称已加密。
- M31 cache-path 收窄与崩溃 zip 用完即删延期：CrashHandler 把 zip 写在 cacheDir 根目录，改成子目录会断崩溃分享，需 CrashHandler 与设置页导出配合改，本版只在 filepaths.xml 注释里写明约束。
- 其余低风险：L14 player/ 与 HistoryStore 大挪移未做（只在注释/口径层面处理，不动包结构）；L18 圆角与主题色口径未统一（只记录，不动功能）；L23 AppGuard 口径（仅启动时检测一次、debug 变体等）未在本版改代码，只沿用 185 口径。
- 在线字幕详情页入口：已穿透所选集；播放页内下载仍沿用旧推导，属已知口径。
- 音乐音源失效源：只在管理页标“已失效”，播放器是否跳过失效源未做，需另定。
