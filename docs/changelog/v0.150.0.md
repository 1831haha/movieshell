# v0.150.0

> 状态：版本档案 ｜ 日期：2026-10-22 ｜ tag v0.150.0

## 新功能

- 循环模式终于真正生效了，顺序播放、单集循环、列表循环不再只是换文案。
- 没设片尾跳过时，自然播完也会自动下一集，不再停在黑屏上。
- 弹幕设置里多了行高，紧凑、标准、宽松三档，弹幕挤不挤自己定。

## 修复

- 修复了循环模式按钮只换文案、从不影响播放的假功能问题。
- 列表循环到最后一集会回到第一集，而不是暂停。

## 已知限制

- 本版改动尚未真机逐项验证。
- 投屏仍是占位按钮，这版不做；IJK 第三内核不做，Media3 加 libmpv 已覆盖。
- 字幕拖拽这次没做，Media3 和 libmpv 两条字幕渲染路子不一样，硬拼容易出冲突，另起设计再做。
